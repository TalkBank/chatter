## Description

Two facts share this code: a main tier's speaker code is not among the
participants `@Participants` declares; or a declared participant has no
`@ID` line.

## Expected Behavior

The participant join reports E522 at the utterance whose speaker is
undeclared (with E308 and W108 saying the same from the model's side),
and at the file for a declared participant without an `@ID`. A file
whose every speaker is declared and every participant has an `@ID` is
not reported.

**Trigger**: See examples above

## CHAT Rule

`@Participants` "lists all of the speakers within the file"
(https://talkbank.org/0info/manuals/CHAT.html#Participants_Header) and "there must be one @ID field for each
participant" (https://talkbank.org/0info/manuals/CHAT.html#ID_Header).
