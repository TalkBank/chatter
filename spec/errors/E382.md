## Description

A `%mor` tier whose content does not parse as morphological items
(`pos|stem` with optional affixes, one per main-tier word).

## Expected Behavior

There is no E382 today: a `%mor` item beginning with `|` is E760, and any
other malformed item leaves the tier unparsable, which is E316 from
recovery with E600 (generic tier error) from validation. A well-formed
tier is not reported. The code stays registered as not implemented until
someone decides whether "the %mor tier failed to parse" deserves its own
verdict over E316.

**Trigger**: See examples above

## CHAT Rule

The `%mor` tier's item format is defined in the manual's dependent-tier
chapter (https://talkbank.org/0info/manuals/CHAT.html#Dependent_Tiers) and in the MOR documentation; a `%mor` line
has one item per word, `pos|stem` with affix codes.
