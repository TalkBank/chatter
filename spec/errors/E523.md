## Description

An `@ID` line names a speaker code that `@Participants` does not declare.

## Expected Behavior

The participant join (`model/participant/join.rs`) reports E523 at the
`@ID` whose code matches no declared participant. An `@ID` for every
declared participant, and none for anyone else, is not reported.

**Trigger**: See examples above

## CHAT Rule

"There must be one @ID field for each participant" (https://talkbank.org/0info/manuals/CHAT.html#ID_Header), and
`@Participants` "lists all of the speakers within the file"
(https://talkbank.org/0info/manuals/CHAT.html#Participants_Header).

## Notes

- The join also reports E522 on the same line today ("speaker code not
  defined in @Participants"), which says the same thing from the
  utterance side; one code should own this.
