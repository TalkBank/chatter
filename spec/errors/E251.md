## Description

E251 reports an empty `WordText`, `WordPhonetic` or `WordShortening` segment.
Each wrapper delegates to `NonEmptyString` validation with the same error code
and its own field label. Checked constructors reject empty strings, but serde
intentionally admits invalid model values so validation can report diagnostics.

## Expected Behavior

Calling `Validate::validate` on a deserialized empty content segment reports
E251. Non-empty content does not report it. The named regression in
`status_note` exercises all three variants at this boundary.

This rule is unreachable from CHAT source. Tree-sitter requires non-empty
word segments and uses checked constructors. The re2c lexer defines `w_text`
with a mandatory first character and `w_short` as `"(" w_text ")"`; its
word-body splitter relies on that lexical guarantee. Phonetic conversion also
uses a checked constructor.

The historical `@s:eng` sample is now owned by E342 as an active example:
it is a malformed word without base text, not an empty model text segment.
Tree-sitter reports E255/E342; re2c reports E209/E253/E255. That recovery
difference is recorded in the backend divergence baseline. E251 carries no
CHAT example; its named model regression supplies coverage.

`chatter from-json` currently deserializes and serializes without model
validation. This specification describes the library validation seam and does
not claim that command reports E251.

## CHAT Rule

Word text and shortening interiors contain at least one character. The model
retains this diagnostic for values admitted through lenient deserialization.
