## Description

A language code that is not in the ISO 639-3 registry, wherever a language
code appears: the `@Languages` header, the language field of `@ID`, an
`@L1 of` header, or a word-level switch (`word@s:CODE`). The placeholder
`xxx` is not a language either.

## Expected Behavior

The parser accepts the header or word with a typed language code; the
validator checks the code against the one shared rule set (shape,
placeholder, registry) and reports E519 at the header or at the word.
One rule with several triggering sites, one code, one spec: until
2026-09-03 the header-level and word-level sites had separate spec files
because `level` was declared per file; since Phase 2 it is declared per
example.

Declaration is a different question: a word-level code need not appear in
`@Languages` (ruling 2026-07-15, part 1); an undeclared utterance-level
precode `[- CODE]` is E755.

**Trigger**: See examples above

## CHAT Rule

"The language codes come from the international ISO 639-3 standard"
(<https://talkbank.org/0info/manuals/CHAT.html#Languages_Header>); the same
codes fill the `@ID` language field
(<https://talkbank.org/0info/manuals/CHAT.html#ID_Header>) and the `@L1 of`
header (<https://talkbank.org/0info/manuals/CHAT.html#L1_Header>), and mark
word-level switches (`@s:` in the special-form markers,
<https://talkbank.org/0info/manuals/CHAT.html#Special_Form_Markers>).

## Notes

- `@L1 of` is held to the registry because wild usage is uniformly ISO
  639-3 (16 distinct values across 1,158 kept files, all valid; ruling
  2026-07-15, part 2).
- Word-level grounding (2026-07-16 probe): all 44 distinct word-level codes
  in the kept corpus are registry-valid, so that site flags nothing today;
  it exists for the historical typo class (`cye`, `sp`, `nle`).
- A RETIRED ISO 639-3 code is a separate, unwritten policy question: a CHAT
  file is a historical document, so a code valid when it was written should
  stay valid (recorded in the CHECK-parity memory, 2026-08-11).
