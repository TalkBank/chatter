## Description

An utterance carries the same dependent tier twice (`%mor` twice, `%com`
twice). Each dependent tier annotates its utterance once; a second copy
either duplicates or contradicts the first.

## Expected Behavior

`validation/utterance/tiers.rs` reports E401 at the second occurrence of a
tier name under one utterance, for every tier name including free-text
ones. Distinct tiers under one utterance are not reported.

**Trigger**: See examples above

## CHAT Rule

Dependent tiers "follow the main tier ... each dependent tier begins with
`%` and a three-letter code" (https://talkbank.org/0info/manuals/CHAT.html#Dependent_Tiers); the manual lists each
tier once per utterance.
