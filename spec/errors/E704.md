## Description

E704 has two independent validation paths:

- **Overlap markers:** adjacent utterances belong to the same speaker; the
  first has a paired top overlap region and the second has a paired bottom
  region. An ordinary continuation without a bottom region is not enough.
- **Media timing:** the current selected utterance bullet starts more than
  500 ms before the same speaker's previous selected bullet ends. Exactly
  500 ms is accepted. This path does not require overlap markers.

The millisecond tolerance belongs only to the timing path. The authored marker
examples do not measure or prove a temporal tolerance.

## Expected Behavior

The first and third examples report E704 for adjacent same-speaker top/bottom
marker pairs. In the legal control, the intervening same-speaker utterance
has no bottom pair; the later other-speaker response does not create that
adjacent self-overlap. Conversely, a later other-speaker response cannot cancel
an already present adjacent same-speaker pair.

For timing, `Utterance::media_bullet()` prefers an explicit final bullet and
otherwise selects the first top-level internal bullet. The validator compares
successive selected intervals for each speaker, not every earlier interval.
It updates speaker state even after reporting an error. Untimed utterances
do not supply an interval; untranscribed speech with a selected bullet does.

The E731 legal example exercises the exact-500-ms timing boundary. The
retained CHECK 133 fixture exercises a larger overlap. E701 and global E362
may independently report start-order problems on the same input.

## CHAT Rule

The marker and temporal contracts are separate. See
[Bullet Validation](../../book/src/architecture/bullet-validation.md) and the
[retained CHECK assessment](../../book/src/architecture/errors-and-validation/check-parity-audit.md)
for their scope. A shared code does not justify rewriting transcription
without reviewing which relationship the diagnostic actually reports.

## Implementation

- Marker relationship: `validation/cross_utterance/mod.rs::check_self_overlap_markers`.
- Timed relationship: `validation/temporal.rs::validate_speaker_timelines`.
- Both owners are in `talkbank-model`; the timing tolerance is
  `SPEAKER_OVERLAP_TOLERANCE_MS`.
