## Description

A replacement scope `[: ...]` is opened and never closed, so the words that
were meant as the replacement target run on into the rest of the utterance.

## Expected Behavior

The raw-text replacement scanner has been removed and E311 is retired.
Existing recovery rejects these malformed inputs without asserting a parsed
replacement. The closed replacement control must remain diagnostic-free.
A direct canonical-fixture test retains this validity boundary independently
of the retired code's deferred spec status.

**Trigger**: See examples above

## CHAT Rule

The CHAT manual's "Replacement" scoped symbol is `[: text]`, attached to the
word it replaces and closed before the next word:
<https://talkbank.org/0info/manuals/CHAT.html#Replacement_Scope>. Scoped
symbols in general are square-bracketed and balanced
(<https://talkbank.org/0info/manuals/CHAT.html#Scoped_Symbols>).
