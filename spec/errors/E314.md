## Description

A scoped annotation is opened with `[` and never given a body or a closing
`]`, so there is no annotation to attach to the preceding word.

## Expected Behavior

Recovery rejects the broken annotation with E316. The complete scoped
annotation control remains accepted. E314 is a retained historical code,
not a requirement to add a second annotation parser or to inspect raw error
text for a more specific diagnostic.

**Trigger**: See example above

## CHAT Rule

Scoped symbols are square-bracketed codes with a body, closed before the next
word: <https://talkbank.org/0info/manuals/CHAT.html#Scoped_Symbols>.
