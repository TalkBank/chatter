## Description

The first start and last end of `%xphoint` must lie within the `*SPK:` media bullet (1 ms tolerance).

## Expected Behavior

- **Parser**: Should succeed, syntax is valid
- **Validator**: Report E744 only when an endpoint exceeds the 1 ms tolerance.
  Missing media timing supplies no bounds comparison. Invalid interval ordering
  remains independently diagnosable as E742.

The authored maximum-integer cases test the numeric boundary, not realistic
recording durations. They must not panic or wrap during tolerance arithmetic.

## CHAT Rule

The first start and last end of `%xphoint` must lie within the `*SPK:` media bullet (1 ms tolerance).
