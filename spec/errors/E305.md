## Description

Main tier is missing its required utterance terminator.

## Expected Behavior

Outside Conversation Analysis mode, the parser retains the utterance content
and validation reports E305 when the typed tier has no terminator. A standard
terminator satisfies the rule. A file declaring `@Options: CA` is exempt from
the ordinary terminator requirement and does not receive E305 solely for this
absence.

**Trigger**: See example above

## CHAT Rule

The CHAT manual's “Basic Utterance Terminators” section requires one utterance
per main line and requires ordinary CHAT utterances to end in `.`, `?`, or `!`:
<https://talkbank.org/0info/manuals/CHAT.html#Utterance_Terminator>. Its
`@Options` section documents that `@Options: CA` removes the usual terminator
requirement for Conversation Analysis transcription:
<https://talkbank.org/0info/manuals/CHAT.html#Options_Header>.

## Notes

- E305 is suppressed for a parse-tainted main tier because recovery may have
  hidden a terminator inside the unparsed region; E316 already records that
  structural failure.
- The same code is used when a parsed `%mor` tier lacks its required
  terminator. This spec exercises the main-tier surface.
