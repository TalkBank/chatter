## Description

Two stress markers are adjacent within one word, so both attempt to annotate
the same following syllabic material. Primary (`ˈ`) and secondary (`ˌ`) stress
must each occur immediately before the material they modify.

## Expected Behavior

The parser builds the word, and validation reports E244 for the adjacent
stress-marker pair. Stress markers separated by spoken material do not trigger
E244.

**Trigger**: See example above

## CHAT Rule

The CHAT manual, section 9.9, “Prosody Within Words,” defines primary and
secondary stress markers as occurring immediately before the stressed
syllable: <https://talkbank.org/0info/manuals/CHAT.html#PrimaryStress_Element>.
Two adjacent markers cannot each satisfy that placement rule for distinct
syllabic material.

## Notes

- E244 is a TalkBank validator enhancement beyond CLAN CHECK, whose audited
  rule set has no direct counterpart for this structural condition.
- Detection is model-level in `validation/word/structure.rs` and examines the
  typed `WordContent` sequence, not the raw source spelling.
- The later-run pair is legal only with respect to E244 after repair: both
  examples retain E247 for multiple primary stress positions. Removing a
  duplicate must not silently choose which distinct syllable should be stressed.
