**Last updated:** 2026-09-08 23:25 EDT

## Description

A `%gra` item the `%gra` parser cannot turn into a relation because its head
field, although lexically a number, is not a head index the model can hold.

## Expected Behavior

`parse_gra_relation` reads the three fields of a `gra_relation` node in order:
index, head, relation name. The index checks report E708 and E709; the head
check is E710, raised when `head_text.parse::<usize>()` fails. Since the
grammar restricts `gra_head` to `/[0-9]+/`, the only head text that reaches the
parser and still fails is a digit run that overflows `usize`, which is what
Example 2 supplies. The relation is then rejected and dropped, never defaulted.

This parser has no other emission site (the re2c backend reports E710 from
its own head parse). Two used to key on an ERROR node whose text
contained `%gra:` (`error_analysis/file.rs`, gone earlier on 2026-09-08 with
the rest of its shadowed `%` block, and `error_analysis/dependent_tier.rs`,
gone later the same day): the second stopped being shadowed once the
dependent-tier readers began reporting their own recovery nodes through that
analyzer, and it then called an `%eng` body that mentioned `%gra:` E710. A
malformed `%gra` line is reported generically (E316), which Example 1
records as subsumption.

**Trigger**: See Example 2 above.

## CHAT Rule

`%gra` items are `index|head|relation` triples, one per `%mor` chunk
(https://talkbank.org/0info/manuals/CHAT.html#GrammaticalRelations_Tier). The
head is `0` for the ROOT attachment or the 1 indexed position of another chunk,
so it is bounded by the length of the utterance.

## Notes

- The name is older than the behaviour: nothing about the surviving route
  involves an unexpected NODE. It is a head field whose VALUE the grammar
  cannot bound and the model cannot represent, which is why the rule has to
  live past the parse rather than in the grammar.
- Previously grouped with E382 and E702 as a retire or implement WP4 item on
  the reading that no CHAT input reaches it. That reading held only for the two
  ERROR node producers; the head overflow route is reachable from ordinary
  bytes and is what Example 2 exercises.
