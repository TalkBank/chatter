## Description

A `%gra` item that is not `index|head|RELATION`, here dashes in place of
the pipes.

## Expected Behavior

The item fails the `%gra` grammar and recovery reports E316 over the
tier; E604 follows because the `%gra` is then present without a usable
`%mor` pairing. `UnexpectedGrammarNode`'s producers
(`tier_parsers/gra/relation.rs`, the ERROR-node classifiers) are reached
only for a node the typed walk did not expect, which raw CHAT does not
produce today. The example records the subsumption.

**Trigger**: See example above

## CHAT Rule

`%gra` items are `index|head|relation` triples, one per `%mor` item
(https://talkbank.org/0info/manuals/CHAT.html#GrammaticalRelations_Tier).
