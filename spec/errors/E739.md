## Description

Every `%xphoaln` pair has exactly one ↔ with a non-null phone on at least one side.

## Expected Behavior

- **Parser**: Should succeed, syntax is valid
- **Validator**: Should report E739

## CHAT Rule

Every `%xphoaln` pair has exactly one ↔ with a non-null phone on at least one side.
