## Description

The parser's typed walk over the concrete syntax tree met something it could
not decode or dispatch: a node whose text is not valid UTF-8, or a node kind
the typed dispatcher for a dependent tier did not expect. This is an
internal invariant, not a property of the CHAT text.

## Expected Behavior

Raw CHAT does not reach E330. The example, an unclosed `<` retrace group, is
a parse failure and is reported as E316 by recovery. The producers of E330
(`typed_cst::decode_present_child`, the `%pho`, `%mor`, `%sin` and
user-defined dependent-tier dispatchers) fire only when the tree handed to
them violates what the grammar guarantees, which is a chatter defect to fix
rather than a transcript to correct.

**Trigger**: See example above

## CHAT Rule

None: there is no CHAT construct this code judges. The retrace group in the
example is governed by the "Retracing" scoped symbols
(<https://talkbank.org/0info/manuals/CHAT.html#Retracing_Scope>), whose
unclosed form is E316's business.

## Notes

- Kept as a registered code because a diagnostic is better than a panic when
  an invariant breaks; a spec cannot demonstrate it from a file, and its
  example stays a documented subsumption.
