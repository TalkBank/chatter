## Description

A `%gra` tier contains a circular dependency when its authored parent edges
contain a directed cycle. Parsing retains the relations; shared validation
reports E724 as an error. Absence of E724 does not prove a valid dependency tree.

## Detection Algorithm

The graph retains every authored edge, including competing edges for a repeated
word index. Choosing the first relation would make cycle detection depend on
source order and let a ROOT edge hide a separate cyclic edge. E721 checks the
independent requirement that indices run sequentially.

Head zero denotes the virtual ROOT and contributes no parent edge. A
self-headed relation labeled ROOT also terminates that edge. A self-headed
non-ROOT relation is a cycle. Unknown positive heads remain terminal graph nodes;
head-range and alignment findings remain independent.

Node identities are resolved once during construction. Iterative DFS visits
each node and edge without recursion or repeated searches of the relation list.
One immutable tier analysis supplies root counts and cycle evidence to the
structural checks. E722 is suppressed when an already-reported cycle explains
the absent root, and whole-tier checks retain their alignment-dispute boundary.

## CHAT Rule

A dependency tree has no cycles, one root and one parent for each non-root word.
Repeated or out-of-sequence indices and invalid head ranges have separate
findings; retaining malformed relations does not make those structures valid.

See the [CHAT grammatical relations documentation](https://talkbank.org/0info/manuals/CHAT.html#GrammaticalRelations_Tier).
