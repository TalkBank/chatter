## Description

CHAT headers with values require a colon followed by a TAB. A generated
`header_sep` with a MISSING tab slot supports E303. An unstructured ERROR
region supports E316, not a reconstruction of the author's header from text.

The `@Recording Quality` TAB deletion leaves the typed missing slot and
therefore reaches E303. The `@Tape Location` deletion and other ERROR-only
examples remain invalid through E316. Their valid controls remain legal.
Neither diagnostic implies the intended header name changed.

CHECK's colon-check observations are comparison evidence, not a requirement
to reproduce its raw-text algorithm or diagnostic granularity. See the
[CHECK assessment](../../book/src/architecture/errors-and-validation/check-parity-audit.md).
