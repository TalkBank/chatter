## Description

A `@Participants` entry has a speaker code but no role.

## Expected Behavior

The participants parser reports E513 at the entry when only one word is
present; the model reports it again for an entry whose role is empty. An
entry `CODE Role` or `CODE Name Role` is not reported.

**Trigger**: See examples above

## CHAT Rule

Each entry is `XXX Name Role`; "participants are identified by three
elements: their speaker ID, their name and their role"
(https://talkbank.org/0info/manuals/CHAT.html#Participants_Header). The name is optional in practice; the role is
not.

## Notes

- A role that is not one of the manual's roles is E532.
