## Description

The `%mod` (model phonology) tier has more tokens than the main tier has
alignable words.

## Expected Behavior

The count-based alignment reports E734 at the tier when the `%mod` token
count exceeds the alignable word count. One token per word is not
reported. `%pho` uses E715.

**Trigger**: See examples above

## CHAT Rule

The `%pho` tier gives the actual phonology of the utterance, one token per
main-tier word (https://talkbank.org/0info/manuals/CHAT.html#Phonology_Tier); `%mod` gives the model (target)
phonology in the same shape (https://talkbank.org/0info/manuals/CHAT.html#Model_Phonology). Alignment between the
main tier and these tiers is by word.
