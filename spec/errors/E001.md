## Description

Internal invariant failure. This error indicates a bug in the parser
itself, not in the CHAT input. It cannot be triggered by any CHAT file.

## Notes

- This code is reserved for internal parser/validator invariant violations.
- No CHAT input can trigger this error; it indicates a programming bug.
- No example is possible or appropriate. That is what `Status:
  unreachable_from_chat` says, and it is what this spec declared in PROSE while
  claiming `implemented` until 2026-08-20: the three sentences above were a
  receipt for a status nobody set.
- Out-of-corpus tests, which is the obligation the status carries:
  `crates/talkbank-model/src/errors/tests.rs`
  (`test_parse_error_at_span_constructor`,
  `test_parse_error_from_source_span_constructor`, `test_parse_errors_separation`)
  construct and assert on this code directly.
