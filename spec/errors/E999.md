## Description

The fallback code for a diagnostic that was built without a specific
code. It names no CHAT rule.

## Expected Behavior

Not reachable from CHAT input. Its producers are internal: the
enhancement layer that decorates diagnostics, and the single-item tier
parser's last resort. A transcript can only ever see it if chatter
constructs a diagnostic incorrectly, and that is the bug to fix.

**Trigger**: See example above

## CHAT Rule

None.

## Notes

- Kept registered so an internal mistake surfaces as a diagnostic rather
