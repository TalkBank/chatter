## Description

An overlap marker has an index value outside the valid range. For CA
overlap brackets (`⌈⌉⌊⌋`), the index must be 2-9. For scoped overlap
annotations (`[<]`, `[>]`), the index must be 1-9.

Scoped indices are admitted at construction, including JSON decoding; an
invalid number cannot become a valid unindexed marker. The primary grammar
rejects zero and multi-digit scoped indices before constructing the model,
so those examples retain their parse-stage recovery diagnostics. Unindexed
markers remain legal and carry no invented numeric default.

Each retained CA point is checked independently, at the point's own source
location. Begin/end pairing does not combine lexical diagnostics, and
word-internal points are not checked again through alignment regions.
Replacement and interposed words receive the same lexical check. JSON readback
preserves invalid indices and their diagnostics even without source locations.

## Expected Behavior

Validation should report E373. Overlap indices must be within valid ranges:
1-9 for scoped overlap annotations, 2-9 for CA overlap point brackets.

## CHAT Rule

Overlap markers use numeric indices to pair overlapping speech segments
between speakers. Valid indices are single digits (1-9 for scoped, 2-9
for CA brackets). See the CHAT manual on overlap conventions.
