## Description

Parser recovery produced a word node whose typed content list is empty. Such a
node does not represent any spoken or annotated word content and cannot be a
valid main-tier item.

## Expected Behavior

The malformed blank main tier is rejected. Current recovery reports E253 for
the empty word state and may also report broader empty-utterance or
missing-required-content diagnostics. A normal nonempty word does not trigger
E253.

**Trigger**: See example above

## CHAT Rule

The CHAT manual defines the main line primarily as a series of words and a
word as a nonempty series of permitted characters and word-internal markers:
<https://talkbank.org/0info/manuals/CHAT.html#Words>. E253 is chatter's
structural recovery invariant for a word node that contains none of those
items.

## Notes

- The fixture currently emits E253 together with E306 and recovery diagnostics;
  E253 specifically names the empty recovered word state.
- The model retains this invalid recovery state so validation can report it;
  successful validation, rather than an unchecked constructor, is the
  transition that excludes it from valid CHAT.
