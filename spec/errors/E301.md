## Description

A main-tier prefix contains `*` and its delimiter but no speaker code, as in
`*:`. The line therefore cannot say which participant produced the utterance.

## Expected Behavior

Tree-sitter recovery recognizes the main-tier-shaped malformed line, and the
parser reports E301 over that recovered region. A main tier with a nonempty
declared code does not trigger E301.

**Trigger**: See example above

## CHAT Rule

The CHAT manual's “Main Line” section requires every main tier to begin with an
asterisk followed by a speaker ID, colon, and tab:
<https://talkbank.org/0info/manuals/CHAT.html#Main_Line>. The speaker ID names
the participant responsible for the utterance; it cannot be empty.

## Notes

- The historical Rust variant is named `MissingMainTier`, but current E301
  behavior is narrower: the source contains a main-tier-shaped line whose
  speaker code is empty. A wholly absent main tier is not an “utterance” for
  this rule to diagnose.
- Recovery recognizes both `*:` and `*` followed directly by a tab as empty
  speaker forms.
