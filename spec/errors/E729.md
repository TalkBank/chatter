## Description

The example's current tier begins before the previous tier ends, and the
tiers belong to different speakers. Their starts remain in document order.
Chatter permits this overlap: E729 is reserved, not an implemented check.
This is distinct from E704's same-speaker timing and marker checks.

The retained CHECK 84 fixture concerns an optional cross-tier constraint
under `+c0`. That comparison does not introduce a default Chatter rule or
waive the independent E362 global start-order requirement.

## Expected Behavior

Default validation accepts this cross-speaker overlap. CHECK emits 84 only
under `+c0`; the parity manifest records the maintainer's July 8 decision
that this optional rule does not bind Chatter parity. E729 is reserved, not
an implemented-but-disabled check or a requirement to reject this example.

## CHAT Rule

Corresponds to CLAN CHECK error 84 ("Current BEG time is smaller than
previous' tier END time"). See CHAT manual on media bullets:
<https://talkbank.org/0info/manuals/CHAT.html#Working_with_Media>
