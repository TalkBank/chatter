## Description

The `%gra` items' own indices do not run 1, 2, 3, ... in order.

## Expected Behavior

`model/dependent_tier/gra/tier.rs` reports E721 at the tier when the
sequence of first fields is not 1..n in order. A tier whose items are
numbered in order is not reported.

**Trigger**: See example above

## CHAT Rule

Each `%gra` item's first number is the position of its word
(https://talkbank.org/0info/manuals/CHAT.html#GrammaticalRelations_Tier), so the items are numbered in order.
