## Description

A replacement must contain at least one intended word. Empty `[: ]` syntax is
rejected during parsing, before a replacement can enter the model. E208 is
retained as a historical diagnostic identifier; model validation no longer
needs an empty-collection branch because checked Rust and JSON admission make
that state unrepresentable.

## Expected Behavior

The primary parser reports E376 for the missing replacement word and E342 for
its recovery slot. The experimental re2c parser rejects the malformed token
sequence through its own grammar; matching tree-sitter recovery diagnostics is
not required. Neither backend may silently accept the empty alternative.

## CHAT Rule

`[: replacement]` requires one or more intended words after the colon. Supply
the intended words or remove the annotation; an empty alternative conveys no
replacement. See <https://talkbank.org/0info/manuals/CHAT.html#Replacement_Scope>.

## Notes

Re2c previously split replacement text, reparsed each word, and could construct
an empty model collection. Structured admission now uses its existing word
productions with a required first word. Model conversion consumes that parsed
structure without reparsing or inventing a plain word when parsing fails.

The subsumption claim remains a regression obligation: retiring E208's model
emit site does not waive rejection of empty replacement syntax. Recovery text
such as the unrelated vocative marker `‡` is not evidence of a replacement.
