## Description

The effective `%xphoaln` actual-side slot count does not match the `%pho`
word count. Model-only pauses consume no actual slot; ordinary lexical
alignment words consume one even if a segment on that side is null.

## Expected Behavior

- **Parser**: Should succeed, syntax is valid
- **Validator**: Should report E728, `%xphoaln` word count (1) does not match `%pho` word count (2)

## CHAT Rule

Each lexical alignment word consumes a `%pho` slot. A single-pair pause
present only on the model side (`(..)↔∅`) consumes no `%pho` slot; its absence
must not shift later words. E728 compares this effective count, not the raw
number of `%xphoaln` entries, against `%pho` (Phon extension spec §2 rule 5).

## Notes

Alignment metadata and reconstruction use the same utterance-owned positional
bindings. The mutation removes one lexical alignment from the pause control;
its diagnostic states both the raw and effective alignment-word counts.
