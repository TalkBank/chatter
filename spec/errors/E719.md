## Description

The `%sin` (sign) tier has more tokens than the main tier has alignable
words.

## Expected Behavior

`alignment/sin.rs` reports E719 at the tier when the token count exceeds
the alignable word count. One token per word is not reported.

**Trigger**: See example above

## CHAT Rule

The `%sin` tier gives a sign for each word of the main tier
(https://talkbank.org/0info/manuals/CHAT.html#Sign_Tier).
