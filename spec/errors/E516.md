## Description

The `@Date` header has no value.

## Expected Behavior

`validation/header/checkers.rs::check_date_header` reports E516 at the
`@Date` when its value is empty; a nonempty value is checked for format
(E518) instead. See E508 for the parser-side twin of this code.

**Trigger**: See examples above

## CHAT Rule

`@Date` gives the date of the interaction as `DD-MMM-YYYY`
(https://talkbank.org/0info/manuals/CHAT.html#Date_Header).
