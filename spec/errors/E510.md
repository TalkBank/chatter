## Description

An `@ID` line's first field, the language, is empty.

## Expected Behavior

`validation/header/checkers.rs::check_id_header` reports E510 at the
`@ID` when the parsed language field is empty. An `@ID` whose first field
holds a code is not reported (whether the code is valid is E519).

**Trigger**: See examples above

## CHAT Rule

The `@ID` fields: "Language: as in the ISO codes table" (https://talkbank.org/0info/manuals/CHAT.html#ID_Header).

## Notes

- The `@ID` must have its ten fields for this rule to be reached; a
  malformed line is E505.
