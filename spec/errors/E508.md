## Description

A `@Date` header with no value. This is the parser-side registration of
the defect that the model reports as E516.

## Expected Behavior

The date header parses with an empty value and validation reports E516;
E508's own producer (`error_analysis/file.rs`, the empty-header check) is
not reached for either spelling of the empty header. The two codes should
be merged; until they are, this spec records the subsumption.

**Trigger**: See example above

## CHAT Rule

`@Date` gives the date of the interaction as day-month-year
(https://talkbank.org/0info/manuals/CHAT.html#Date_Header); an empty one gives nothing.
