## Description

A media bullet `\u0015START_END\u0015` whose start or end is not a
millisecond count.

## Expected Behavior

Such a bullet is not a bullet to the grammar and is reported as E316
(unparsable content). E361 is registered for a value-level timestamp error
but nothing produces it: a bullet that parses always has two integers, and
the relation between them is E362's business. A numeric bullet is not
reported.

**Trigger**: See example above

## CHAT Rule

The CHAT manual's "Time Alignment" scope defines the bullet as two
millisecond counts separated by an underscore, between two U+0015
delimiters, after the terminator and any postcodes:
<https://talkbank.org/0info/manuals/CHAT.html#TimeAlignment_Scope>,
<https://talkbank.org/0info/manuals/CHAT.html#Utterance_Media>.

## Notes

- The non-numeric example is already rejected by the grammar/recovery path.
  Do not broaden the bullet grammar merely to produce E361. A distinct
  value-level check requires a demonstrated invalid case not already handled
  by the existing timestamp diagnostics. Registry retirement is a separate
  compatibility decision, not a reason to add duplicate validation.
