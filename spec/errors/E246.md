## Description

Word-internal lengthening (`:`) requires preceding spoken material. A
shortening records omitted material, so `(he):` has nothing spoken to lengthen
and reports E246 as well as E209 (a shortening-only word). `hel:o` and
`(he)l:o` have preceding spoken text and do not violate this rule.

## Expected Behavior

`validation/word/structure.rs::ProsodicWord` checks the typed
word-content sequence. A `Lengthening` element must have an earlier spoken
text element. This validator is implemented; its former deferred example did
not exercise it.

At the beginning of a main-tier item, `:hello` parses as a separator followed
by a word, not as word-internal lengthening. Its missing space is E765, so the
original example now asserts that subsumption. Do not change the grammar or
emit a second code merely to force this shape through the lengthening check.

## Boundaries

The examples retain the original separator-spacing case, add a reachable
lengthening violation, and pin legal lengthening with and without an initial
shortening. The shared observation snapshot records exact diagnostics;
E246's claim only asserts this rule's presence or absence.
