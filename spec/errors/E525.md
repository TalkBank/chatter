**Last updated:** 2026-09-03 18:09 EDT

## Description

A line begins with `@` and a name that is not a CHAT header. Modern CHAT has
a closed set of headers and no "soft" kinds; free text belongs in
`@Comment` or `@Situation`, not under an invented name.

## Expected Behavior

The header parser recognizes no header of that name and validation reports
E525 over the line, naming it (`validation/header/unknown.rs`), with a
pointer to the manual's header list. Every header the manual defines is
known; `@Comment` in particular accepts any text.

**Trigger**: See examples above

## CHAT Rule

The CHAT manual's "File Headers" chapter is the closed list:
<https://talkbank.org/0info/manuals/CHAT.html#File_Headers>. A legacy
`@Page` header is reported under this code too, with its own message.

## Notes

- Until 2026-09-03 this spec carried four gem examples (nested `@Bg`, `@G`
  inside a scope, unmatched `@Bg`, unmatched `@Eg`) subsumed by E529, E530,
  E526 and E527; they belong to those codes, where each has its own
  example, and were removed here.
- A header with a known name but a malformed value is a different code
  (E505 for `@ID`, the `Empty...Header` family for empty values).
