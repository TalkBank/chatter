## Description

A `@Birth of XXX` header names a speaker code that `@Participants` does
not declare.

## Expected Behavior

The participant join reports E524 at the `@Birth` header whose code
matches no declared participant. A `@Birth` for a declared participant is
not reported.

The timed control extends the declared-participant example with linked media
and one recorded utterance interval. Its companion changes only the birth
header's speaker reference. Timing neither repairs nor relaxes participant
identity: a transform that removes that declaration must still report the
orphaned birth header rather than silently dropping or retargeting it.

**Trigger**: See examples above

## CHAT Rule

`@Birth of #` is a participant-specific header, one of those that "follow
the @ID headers" for a declared participant (https://talkbank.org/0info/manuals/CHAT.html#Birth_Header).
