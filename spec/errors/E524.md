## Description

A `@Birth of XXX` header names a speaker code that `@Participants` does
not declare.

## Expected Behavior

The participant join reports E524 at the `@Birth` header whose code
matches no declared participant. A `@Birth` for a declared participant is
not reported.

**Trigger**: See examples above

## CHAT Rule

`@Birth of #` is a participant-specific header, one of those that "follow
the @ID headers" for a declared participant (https://talkbank.org/0info/manuals/CHAT.html#Birth_Header).
