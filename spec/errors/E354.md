## Description

An other-completion linker (`++`) was used and the preceding utterance is
from a different speaker, but that preceding utterance did not end with
`+...` (trailing off). The other-completion convention requires the
previous speaker to have trailed off.

## Expected Behavior

Validation should report E354. CHI uses `++` (other-completion), which
requires MOT's preceding utterance to have ended with `+...` (trailing
off). But MOT's utterance ends with `.` (normal terminator).

## CHAT Rule

The `++` linker pairs with `+...`. Speaker B uses `++` to complete
Speaker A's trailed-off utterance. Speaker A must end with `+...`.

This is an optional strict-linker rule. An absent terminator is not evidence
of trailing off, even when CA mode waives the ordinary terminator requirement.
The deletion examples retain the parsed turns and distinguish E305's policy
from E354's policy instead of treating absence as a fabricated `+...` token.

CHECK 21-Sep-2026, observed 2026-09-23, reported error 21 for the ordinary
terminator-deletion example and no errors for the control or CA example.
Chatter's E305 matches that ordinary-versus-CA distinction; E354 remains
separately opt-in rather than being attributed to CHECK.
