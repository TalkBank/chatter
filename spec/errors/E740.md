## Description

Concatenating the model (left) sides of `%xphoaln`, skipping ∅, must
reproduce the `%mod` word. The comparison is segment-level: stress markers (`\u{02C8}`, `\u{02CC}`)
and syllable-boundary notation (Phon's `^`, IPA's `.`) in either string are
ignored, and the linking tie (`\u{203F}`, which joins two symbols into one
segment or marks the absence of a break) is ignored in the `%mod` word,
since the alignment pairs carry bare segments while the source word may
carry suprasegmental, boundary and linking notation. A pair side that
carries a tie is not a bare segment and is compared as written.

A pause present only on the actual side consumes no model word slot.
Reconstruction advances the model cursor independently, using the same
positional binding as E727/E728 count checks (Phon extension spec §2 rule 5).

## Expected Behavior

- **Parser**: Should succeed, syntax is valid
- **Validator**: Should report E740
