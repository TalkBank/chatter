## Description

The `@Media` header's filename and the transcript's own filename are the same
name except for letter case, for example `Session.cha` declaring
`@Media: session, audio`. CHECK compares these two names without regard to
case (error 157 uses a case-insensitive comparison), so this is not the real
filename mismatch that E531 reports. It is still a defect in the names: a
recording is looked up by the name `@Media` gives, and a name that differs only
in case is found on a case-insensitive filesystem (macOS by default) and not on
a case-sensitive one. The same transcript then finds its media on one host and
loses it on another. TalkBank names must match exactly.

## Expected Behavior

`check_media_filename_match`
(`crates/talkbank-model/src/model/file/chat_file/validate/checks.rs`) compares
the two names under Unicode NFC and ASCII case folding first. If they differ
there, it reports E531 as before. If they agree there but the NFC forms differ
in letter case, it reports W110, naming both spellings. W110 and W109 are
independent: a name can differ in case and also be spelled in a non-NFC form,
and each warning then reports its own fact.

**Trigger conditions**: `@Media` filename and the CHAT file's own name are equal
under ASCII case folding after NFC normalization, and not equal without it.
Remote URLs are exempt, as for E531.

**Repair**: make the two names identical. Either update `@Media` to the file
name's spelling or rename the transcript, and make sure the recording itself
carries the same spelling. `chatter fix` has no automatic repair for W110,
because which spelling the recording on disk uses is not visible to it.

## CHAT Rule

The CHAT manual requires the `@Media` name to match the data file name (see
E531). CLAN's CHECK makes that comparison case-insensitive; this warning is a
TalkBank naming-consistency rule layered on top, so the match holds on every
filesystem rather than only on case-insensitive ones.

## Notes

- Case folding is ASCII only, matching E531's comparison: two names that
  differ in the case of a non-ASCII letter are E531.
- CLI-level coverage lives in
  `crates/chatter/tests/integration/media_filename_match_tests.rs`, alongside
  E531 and W109, because the check depends on the caller-provided file name.
