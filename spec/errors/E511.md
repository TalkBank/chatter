## Description

An `@ID` line's third field, the speaker code, is empty, so the line
describes nobody.

## Expected Behavior

`check_id_header` reports E511 at the `@ID`. Because the line then matches
no declared participant, E523 (orphan `@ID`) follows, and the declared
participant is left without an `@ID` (E522). An `@ID` naming a declared
code is not reported.

**Trigger**: See examples above

## CHAT Rule

The `@ID` "Code: the three-letter code for the speaker in capitals"
(https://talkbank.org/0info/manuals/CHAT.html#ID_Header).
