## Description

The file lacks one of the headers every CHAT file must have: `@Begin`,
`@Languages` or `@Participants`.

## Expected Behavior

`validation/header/structure.rs` counts headers by name and reports E504
once per missing required header, anchored at the end of the file (there
is no line to point at), naming the header. A missing `@Participants` also
leaves every speaker undeclared (E522) and puts `@ID` out of order (E543);
those are consequences, not this rule.

**Trigger**: See examples above

## CHAT Rule

The manual's obligatory headers: `@Begin` (https://talkbank.org/0info/manuals/CHAT.html#Begin_Header), `@Languages`
("the second visible header", https://talkbank.org/0info/manuals/CHAT.html#Languages_Header) and `@Participants`
("the third visible header ... obligatory", https://talkbank.org/0info/manuals/CHAT.html#Participants_Header).

## Notes

- `@UTF8` and `@End` are required too but are checked by their own rules
  (E101 for the encoding line, E502 for the missing end).
- `@ID` is not on the required list: a participant without an `@ID` is
  reported through the participant join, not here.
