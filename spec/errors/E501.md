## Description

A header that a file may carry only once appears twice: `@UTF8`, `@Begin`,
`@End`, `@Languages`, `@Media`, `@Videos` or `@Types`.
This is an occurrence rule, not a claim that the repeated values are identical.
Conflicting declarations require establishing the intended information; the
diagnostic alone cannot determine which declaration should be retained.

## Expected Behavior

The duplicate Begin/End fixtures are rejected by E316 at unstructured recovery
slots. Other single-occurrence headers are counted by `validation/header/structure.rs` and a count above
one is reported as E501 at the repeated header. Headers the manual allows
to repeat (`@Comment`, `@Situation`, `@ID`, the gem headers) are not this
rule's business, and a repeated `@Participants` is not reported by it either
(see Notes).

The duplicate-End example must retain E316 with or without a terminal newline:
tree-sitter may move the extra End outside the concrete document node, but that
does not change the single-occurrence rule.

**Trigger**: See examples above

## CHAT Rule

The CHAT manual's "File Headers" chapter defines `@UTF8`, `@Begin` and
`@End` as the fixed frame of a file (https://talkbank.org/0info/manuals/CHAT.html#File_Headers, https://talkbank.org/0info/manuals/CHAT.html#Begin_Header,
https://talkbank.org/0info/manuals/CHAT.html#End_Header) and `@Media` as one header per file (https://talkbank.org/0info/manuals/CHAT.html#Media_Header).

## Notes

- The closed list is `["Languages", "Types", "Media", "Videos", "UTF8",
  "Begin", "End"]` in `structure.rs`. A duplicated `@Participants` is still
  accepted; whether it should be is a WP4 question.
- `@Languages` joined the list in September 2026. A second declaration leaves
  the primary language ambiguous, and merge already refused such inputs. No
  TalkBank data file carries two (0 of 106,705 `.cha` files after `tb pull`,
  September 14, 2026).
  CLAN CHECK does not report a repeated `@Languages`: `check.cpp` has no
  single-use rule for it, and its dependency file lists it only as an allowed
  header. Chatter goes beyond CHECK here on purpose: a repeated `@Languages`
  is invalid CHAT by maintainer ruling, not a provisional behavior.
