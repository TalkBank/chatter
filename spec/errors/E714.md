## Description

The `%pho` (actual phonology) tier has fewer tokens than the main tier
has alignable words, so the last words have no transcription.

## Expected Behavior

The count-based alignment (`model/file/utterance/metadata/alignment/`)
compares the `%pho` token count with the main tier's alignable words and
reports E714 at the tier when there are too few. One token per word is
not reported. `%mod` has its own pair (E733/E734); `%wor` is a timing
sidecar and is never count-checked.

The grouped control combines the main-tier shape in
`corpus/reference/annotation/groups-phonological.cha` with a phonological pause.
Its paired mutation deletes only the last `%pho` token. The diagnostic must
retain the whole phonological group as one position and display the pause,
not expand the group's words or silently omit the pause.

**Trigger**: See examples above

## CHAT Rule

The `%pho` tier gives the actual phonology of the utterance, one token per
main-tier word (https://talkbank.org/0info/manuals/CHAT.html#Phonology_Tier); `%mod` gives the model (target)
phonology in the same shape (https://talkbank.org/0info/manuals/CHAT.html#Model_Phonology). Alignment between the
main tier and these tiers is by word.
