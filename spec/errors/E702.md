## Description

A `%mor` item with no `|` between its part of speech and its stem, so
neither field can be told from the other.

## Expected Behavior

There is no E702 today: the item fails the `%mor` grammar and the tier is
reported as E316 (unparsable content) from recovery with E600 from
validation. `InvalidMorphologyFormat`'s only producer is an ERROR-node
classifier (`error_analysis/dependent_tier.rs`) that the `%mor` recovery
route does not reach. The registry lists the code as not implemented.

**Trigger**: See example above

## CHAT Rule

`%mor` items are `pos|stem` with optional prefix, suffix and translation
fields (https://talkbank.org/0info/manuals/CHAT.html#MOR_Format).
