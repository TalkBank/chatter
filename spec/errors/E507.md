## Description

The `@Languages` header names no language.

## Expected Behavior

The languages parser reports E507 whether the value is absent, empty or
whitespace; with the value absent the header does not count as present
either, so E504 (missing required header) accompanies it. A header with at
least one ISO 639-3 code is not reported.

**Trigger**: See examples above

## CHAT Rule

`@Languages` "tells the programs which language is being used", as one
or more ISO 639-3 codes (https://talkbank.org/0info/manuals/CHAT.html#Languages_Header).

## Notes

- Which codes are valid is E519's rule, not this one.
