## Description

An `@Options` header with no option named.

## Expected Behavior

The model reports E533 at an `@Options` whose value is empty. An
`@Options` naming at least one option (for example `CA`) is not reported
by this rule; which options exist, and the CA and IPA combination, are
other rules.

**Trigger**: See examples above

## CHAT Rule

`@Options` "is not obligatory ... when it occurs, it must follow the
@Participants line" and names options whose spelling is case-sensitive
(https://talkbank.org/0info/manuals/CHAT.html#Options_Header).
