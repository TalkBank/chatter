## Description

The `@Media` header names no media file.

## Expected Behavior

The parser's header analysis reports E509 over a `@Media` whose value is
absent or whitespace. A header of the form `name, type` is not reported by
this rule (its name is matched against the file by E531 and its type by
its own rule).

**Trigger**: See examples above

## CHAT Rule

`@Media` names the media file and its type (https://talkbank.org/0info/manuals/CHAT.html#Media_Header).

## Notes

- The empty-value check lives in two places (the parser's ERROR analysis
  for `@Media:` and the header parser for `@Media:` + tab); both report
  E509.
