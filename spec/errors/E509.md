## Description

The `@Media` header names no media file.

## Expected Behavior

The empty and whitespace-only source examples produce unstructured recovery,
reported as E316. The parser does not scan an ERROR prefix to reconstruct
a media header or manufacture an E509 diagnosis. A typed header of the form
`name, type` is not reported by
this rule (its name is matched against the file by E531 and its type by
its own rule).

**Trigger**: See examples above

## CHAT Rule

`@Media` names the media file and its type (https://talkbank.org/0info/manuals/CHAT.html#Media_Header).

- These fixtures establish source rejection through E316, not reachability of
