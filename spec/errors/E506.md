## Description

The `@Participants` header is present but declares nobody.

## Expected Behavior

The participants parser reports E506 when the header's value is empty or
whitespace, and the model reports it again when the entry list is empty;
the observation snapshot records which fired. Every utterance in such a
file is then by an undeclared speaker (E522). A header declaring at least
one `CODE Role` entry is not reported.

**Trigger**: See examples above

## CHAT Rule

`@Participants` "lists all of the speakers within the file", each as
`XXX Name Role` with the name optional (https://talkbank.org/0info/manuals/CHAT.html#Participants_Header).

## Notes

- An entry with a code but no role is E513; a single word that is neither
  is read as a code without a role, also E513 (E512 is unreachable, see
  its spec).
