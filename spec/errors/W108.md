## Description

A main tier's speaker code is not among the participants the file
declares.

## Expected Behavior

The model attaches W108 to the utterance as a warning
(`model/content/main_tier/mod.rs`); the validator reports the same fact as
E522 and E308. An utterance by a declared speaker carries none of them.

**Trigger**: See examples above

## CHAT Rule

`@Participants` "lists all of the speakers within the file"
(https://talkbank.org/0info/manuals/CHAT.html#Participants_Header); every main tier names one of them
(https://talkbank.org/0info/manuals/CHAT.html#Utterance_Speaker_Code).

## Notes

- Which of W108, E522 and E308 should own this fact is open; the warning
  form predates the two errors and is kept for consumers that ask for
  warnings only.
