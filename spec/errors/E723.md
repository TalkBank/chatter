## Description

More than one item of the `%gra` tier is a ROOT.

## Expected Behavior

`gra/tier.rs` reports E723 at the tier when two or more items carry the
ROOT relation. Exactly one is not reported; none is E722.

**Trigger**: See example above

## CHAT Rule

One ROOT per `%gra` tier (https://talkbank.org/0info/manuals/CHAT.html#GrammaticalRelations_Tier).
