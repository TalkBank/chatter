## Description

A media bullet's times run backwards: its end is not after its start, or
it starts earlier than the bullet before it.

## Expected Behavior

`validation/bullet.rs` reports E362 for a bullet whose start is not less
than its end (`check_bullet`), and again for a bullet whose start is less
than the previous bullet's start (`check_bullet_monotonicity`), each at the
offending bullet. Bullets with `start < end` in nondecreasing order are not
reported.

**Trigger**: See examples above

## CHAT Rule

The CHAT manual's "Time Alignment" scope: the bullet gives the begin and
end of the utterance in milliseconds, and utterances are transcribed in
time order:
<https://talkbank.org/0info/manuals/CHAT.html#TimeAlignment_Scope>. CLAN
CHECK's error 83 covers the ordering half.

## Notes

- A zero-length bullet (`1000_1000`) is reported: the rule is strict
  `start < end`.
- The E701 that accompanies the sequence example is the tier-level "begin
  time is not monotonically increasing" rule, a separate spec.
