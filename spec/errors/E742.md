## Description

Each `%xphoint` phone interval must have start strictly less than end.

## Expected Behavior

- **Parser**: Should succeed, syntax is valid
- **Validator**: Should report E742

## CHAT Rule

Each `%xphoint` phone interval must have start strictly less than end.
