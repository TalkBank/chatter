# E252

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Syntax error - caret at word start

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

### Description

The syllable-pause marker (`^`) occurs without spoken material on both sides
inside the same word. A leading or trailing caret cannot mark a pause *between*
syllables.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
@Comment:	Caret for pause between syllables must appear MID-WORD (e.g., rhi^noceros)
@Comment:	not at the start of a word
*CHI:	^test .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	test^ .
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	rhi^noceros .
@End
```

### CHAT Rule

The CHAT manual, section 9.9, “Prosody Within Words,” defines `^` as a pause
between syllables and illustrates it with `rhi^noceros`:
<https://talkbank.org/0info/manuals/CHAT.html#X67454>.

## Leading and trailing pauses remain invalid among structural markers

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

Overlap and underline markers do not supply the spoken material required on
both sides of a syllable pause. The grammar admits the structured word so the
existing E252 validation rule can diagnose its edge pause. Parsing, source
spelling, validation and file-mode policy remain distinct. The legal stacked
controls travel the marker-initial word-body choice conversions.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
@Comment:	Stacked marker controls
*SPK:	⌈⌊orchid⌋⌉ ⌈thistle⌉ ⌈clo↑ver⌉ ⌈la~ven+der⌉ ⌈peˈtal⌉ ⌈ir^is⌉ .
@End
```

boundary. Recovery does not certify validity or permit fabricated speaker or
spoken material. The fully admitted controls remain independently required.
