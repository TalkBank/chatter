# E715: %pho has more tokens than the main tier has words

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

The `%pho` (actual phonology) tier has more tokens than the main tier
has alignable words.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|2;06.|male|||Target_Child|||
*CHI:	want cookie .
%pho:	aɪ wɑnt kʊki
@Comment:	ERROR: Main tier has 2 words but %pho has 3 tokens (extra aɪ)
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	want cookie .
%pho:	wɑnt kʊki
@End
```

## CHAT Rule

The `%pho` tier gives the actual phonology of the utterance, one token per
main-tier word (https://talkbank.org/0info/manuals/CHAT.html#Phonology_Tier); `%mod` gives the model (target)
phonology in the same shape (https://talkbank.org/0info/manuals/CHAT.html#Model_Phonology). Alignment between the
main tier and these tiers is by word.
