# E207: Unknown or incomplete annotation marker

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word, utterance

**Status**: ✅ Active

## Description

Unknown scoped markers and incomplete ampersand forms remain invalid. Their
ERROR regions receive E316 without reconstructing an annotation from text.
The paired explanation and filler controls remain legal. The host-deletion
pair retains E316 and E342; recovery is not acceptance.

Typed `ContentAnnotation::Unknown` validation remains a separate model
boundary with its own diagnostic. These source fixtures do not prove that
boundary reachable. Word-suffix forms are independently governed by E203.
