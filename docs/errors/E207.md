# E207: Unknown scoped annotation marker

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

## Description

A `[...]` scoped annotation whose marker CLAN/chatter does not recognize as
one of the defined scoped-annotation types (e.g. `[: text]` replacement,
`[/]` retracing, `[* code]` error coding, and the rest of the closed set the
grammar defines). The bracket syntax parses; the marker inside it does not
match any known annotation rule, so it reaches the model as
`ContentAnnotation::Unknown` and is reported as a validity question rather
than a parse failure.

`hello [@ xyz] world .` is invalid because `@` is not a defined scoped
annotation marker (word-level `@` suffixes like `@b`/`@c` are a completely
different construct, a word-suffix rather than a bracketed annotation; see E203).

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello [@ xyz] world .
@End
```

## CHAT Rule

<https://talkbank.org/0info/manuals/CHAT.html#Scoped_Symbols> lists the closed
set of defined scoped-annotation markers. A marker outside that set is not
valid CHAT; chatter reports it as E207 rather than silently accepting it or
downgrading the whole utterance to an unparsable-content error (E321/E316).
