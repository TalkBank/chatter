# E712: %gra word index out of range

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

A `%gra` relation's word index is outside the one-based range of `%mor`
chunks, including clitics and the terminator. The violating example uses
word index 5 for a tier containing three chunks. Head-index errors are E713.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	ERROR: Grammar relation word index out of bounds
*CHI:	I want .
%mor:	pro|I v|want .
%gra:	1|2|NSUBJ 5|0|ROOT 3|2|PUNCT
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I want .
%mor:	pro|I v|want .
%gra:	1|2|NSUBJ 2|0|ROOT 3|2|PUNCT
@End
```

## CHAT Rule

Each `%gra` relation has the form `index|head|relation`. Its word index names
a one-based `%mor` chunk position, not a morphological item; a clitic-bearing
item contributes multiple chunks. The terminator also occupies a position.
