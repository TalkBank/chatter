# E712: %gra word index out of range

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

A `%gra` item's index or head number does not correspond to any item of
the `%mor` tier it annotates (here a head of 5 over a two-word
utterance).

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	ERROR: Grammar relation word index out of bounds
*CHI:	I want .
%mor:	pro|I v|want .
%gra:	1|2|NSUBJ 5|0|ROOT 3|2|PUNCT
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I want .
%mor:	pro|I v|want .
%gra:	1|2|NSUBJ 2|0|ROOT 3|2|PUNCT
@End
```

## CHAT Rule

`%gra` "indicates the dependency structure by giving, for each word, its
index, the index of its head and the relation"
(https://talkbank.org/0info/manuals/CHAT.html#GrammaticalRelations_Tier); an index names a `%mor` item.
