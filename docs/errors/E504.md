# E504: Missing required header

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

The file lacks one of the headers every CHAT file must have: `@Begin`,
`@Languages` or `@Participants`.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

## CHAT Rule

The manual's obligatory headers: `@Begin` (https://talkbank.org/0info/manuals/CHAT.html#Begin_Header), `@Languages`
("the second visible header", https://talkbank.org/0info/manuals/CHAT.html#Languages_Header) and `@Participants`
("the third visible header ... obligatory", https://talkbank.org/0info/manuals/CHAT.html#Participants_Header).
