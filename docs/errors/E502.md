# E502: Missing @End

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

The file has no `@End` header.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello world .
```

## CHAT Rule

`@End` is the last line of every CHAT file (https://talkbank.org/0info/manuals/CHAT.html#End_Header).
