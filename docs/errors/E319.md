# E319: UnparsableLine

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

## Description

The retained malformed-line fixture is rejected by E316. A percent prefix
in recovery text does not establish a dependent-tier identity or justify E602.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|test|CHI||female|||Target_Child|||
*CHI:	hello .
%%%broken line content here
@End
```
