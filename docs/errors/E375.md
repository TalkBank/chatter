# E375: Scoped annotation parse error

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word, utterance

**Status**: ✅ Active

## Description

A scoped annotation (a square-bracketed code) cannot be parsed where it
stands: brackets nested past any CHAT form, or a replacement glued to its
word with no space before the `[`.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
@Comment:	Note: This may need adjustment after testing
*CHI:	hello [[[[ test ]]]] world .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	word[: foo] .
@End
```

### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	TEA Teacher
@ID:	eng|corpus|TEA|||||Teacher|||
*TEA:	“plant” [//] plant .
@End
```

## CHAT Rule

Scoped symbols are square-bracketed and preceded by a space
(https://talkbank.org/0info/manuals/CHAT.html#Scoped_Symbols); CLAN CHECK error 161 states the space requirement.
