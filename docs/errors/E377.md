# E377: A retracing marker with no material of its own

> ✅ Active; This check is active in the validator.

**Severity**: error

**Status**: ✅ Active

## Description

A retracing marker whose only content is another retracing marker, so it has no material of its own to retrace. A marker retraces the words immediately to its left, and a marker is not words.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	ERROR: the second marker has nothing before it to retrace
*CHI:	the [//] [/] the dog .
@End
```
