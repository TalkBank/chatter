# E387

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Replacement on a phonological fragment

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A replacement `[: text]` is attached to a phonological fragment (`&+`), a
piece of a word that was never a word and has no standard form to replace.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	&+ba [: dog] .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	&+ba dog .
@End
```

### CHAT Rule

The manual's Replacement scope `[: text]`: "the item being replaced can
only be a single word" that MOR should analyse under its standard form
(https://talkbank.org/0info/manuals/CHAT.html#Replacement_Scope, https://talkbank.org/0info/manuals/CHAT.html#Replacement_Real). A phonological fragment is not a word
(https://talkbank.org/0info/manuals/CHAT.html#PhonologicalFragment_Code).

## Replacement on a fragment with word-internal features

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

Lengthening, segment repetition and phonetic form preserve the `&+`
phonological-fragment category. They do not make the fragment a word eligible
for a replacement. Each invalid example adds only one replacement annotation
to its adjacent legal control.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
*SPK:	&+br: [: branch] .
@End
```

### CHAT Rule

The existing E387 rule applies to the produced fragment regardless of its
word-internal features or form suffix. A fragment without a replacement is
legal; attaching `[: text]` to it is not. Plain-fragment controls remain in
`E387.md`.
