# E505: Invalid @ID format

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

An `@ID` line does not have the shape the manual prescribes: ten
pipe-separated fields, each of which may be empty.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus
*CHI:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus||
*CHI:	hello .
@End
```

### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	|corpus|CHI|
*CHI:	hello .
@End
```

### Example 4

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

## CHAT Rule

The manual's `@ID` header: `@ID: language|corpus|code|age|sex|group|SES|role|education|custom|`,
one per participant, fields left empty when unknown (https://talkbank.org/0info/manuals/CHAT.html#ID_Header).
