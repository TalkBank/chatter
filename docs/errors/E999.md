# E999: Unknown error (internal fallback)

> ⏳ Planned; This check is documented but not yet enforced by the validator. The error code will not fire until implementation is complete.

**Kind**: Invalidity

**Level**: tier

**Status**: ⏳ Planned

## Description

The fallback code for a diagnostic that was built without a specific
code. It names no CHAT rule.
