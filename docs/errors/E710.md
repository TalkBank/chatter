# E710: Unexpected node in %gra

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

A `%gra` item that is not `index|head|RELATION`, here dashes in place of
the pipes.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello world .
%gra:	1-2-SUBJ 2|0|ROOT
@End
```

## CHAT Rule

`%gra` items are `index|head|relation` triples, one per `%mor` item
(https://talkbank.org/0info/manuals/CHAT.html#GrammaticalRelations_Tier).
