# E522: Speaker not declared, or declared without an @ID

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance, header

**Status**: ✅ Active

## Description

Two facts share this code: a main tier's speaker code is not among the
participants `@Participants` declares; or a declared participant has no
`@ID` line.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*MOT:	hello dear .
*CHI:	hi mommy .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Ruth Target_Child, MOT Mother
@ID:	eng|corpus|MOT|||||Mother|||
*CHI:	hello .
*MOT:	hi there .
@End
```

## CHAT Rule

`@Participants` "lists all of the speakers within the file"
(https://talkbank.org/0info/manuals/CHAT.html#Participants_Header) and "there must be one @ID field for each
participant" (https://talkbank.org/0info/manuals/CHAT.html#ID_Header).
