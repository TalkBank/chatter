# E506: Empty @Participants header

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

The `@Participants` header is present but declares nobody.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

## CHAT Rule

`@Participants` "lists all of the speakers within the file", each as
`XXX Name Role` with the name optional (https://talkbank.org/0info/manuals/CHAT.html#Participants_Header).
