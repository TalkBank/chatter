# E404: Orphaned dependent tier

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

Dependent tiers require a parent main tier. This fixture has no admitted tier
node at its top-level recovery slot, so tree-sitter reports E316 rather than
reconstructing a dependent tier from a percent-prefixed substring. It remains
invalid. E404 is not required to label this recovery shape.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
%mor:	co|hello .
*CHI:	hello .
@End
```
