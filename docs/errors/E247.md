# E247: Multiple primary stress markers in one word

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

## Description

A single CHAT word contains more than one primary-stress marker (`ˈ`). The
word-level model permits one primary stress and may additionally carry
secondary stress before another syllable.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	ERROR: Word can only have one primary stress
@Comment:	Invalid: 'ˈheˈllo' - Two primary stress markers
*CHI:	ˈheˈllo .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	ˈhello .
@End
```

## CHAT Rule

The CHAT manual, section 9.9, “Prosody Within Words,” distinguishes primary
stress (`ˈ`) from secondary stress (`ˌ`) and places each immediately before
the stressed syllable:
<https://talkbank.org/0info/manuals/CHAT.html#PrimaryStress_Element>. The
manual does not state a separate cardinality diagnostic; E247 is chatter's
additional structural invariant that a single word token records at most one
primary stress.
