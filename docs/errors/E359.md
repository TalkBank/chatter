# E359: Unmatched long-feature end

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

## Description

A long-feature end marker `&}l=LABEL` has no open `&{l=LABEL` with the same
label before it.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	happy birthday to you &}l=singing .
*CHI:	another utterance .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I am &{l=singing happy birthday .
*CHI:	to you &}l=singing .
@End
```

## CHAT Rule

The CHAT manual's "Long Events" section (9.10.5 in the current manual, which
has no named anchor for it; `#_Toc208734929` in the 2026-09-03 build) defines
`&{l=LABEL` and `&}l=LABEL` as the begin and end of a long event, and the
matching nonvocal pair `&{n=LABEL` / `&}n=LABEL`; the labels of a pair are the
same, and the pair may span several utterances of one file.
