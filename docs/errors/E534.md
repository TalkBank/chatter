# E534: Unsupported @Options Value

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

An `@Options` header contains a flag that is not one of the recognized option values. The file parses successfully but the unsupported flag is stored as `Unsupported(String)` and flagged during validation.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Options:	badoption
*CHI:	hello world .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@Options:	CA, IPA
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hey .
@End
```

### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@Options:	CA, NoAlign
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hey .
@End
```

### Example 4

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@Options:	NoAlign, CA
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hey .
@End
```

## CHAT Rule

The `@Options` header accepts the recognized flags `CA` and `NoAlign`.
Other values, including legacy `IPA`, are preserved but reported as unsupported.

Reference: <https://talkbank.org/0info/manuals/CHAT.html#Options_Header>
