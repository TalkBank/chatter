# E722: %gra has no ROOT

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

No item of the `%gra` tier has head 0 and relation ROOT, so the
dependency tree has no root.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I want .
%mor:	pro|I v|want .
%gra:	1|2|NSUBJ 2|3|OBJ 3|0|PUNCT
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I want .
%mor:	pro|I v|want .
%gra:	1|2|NSUBJ 2|0|ROOT 3|2|PUNCT
@End
```

## CHAT Rule

One item of the `%gra` tier is the ROOT, with head 0
(https://talkbank.org/0info/manuals/CHAT.html#GrammaticalRelations_Tier).
