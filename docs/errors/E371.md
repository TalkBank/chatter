# E371: Pause inside a phonological group

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

## Description

A pause marker (`(.)`, `(..)`, `(...)` or a timed `(1.5)`) appears inside a
phonological group `‹...›`. A phonological group marks words
pronounced as one unit, which a pause contradicts.

## CHAT Rule

The CHAT manual's "Phonological Group" scoped symbol
(<https://talkbank.org/0info/manuals/CHAT.html#Phonological_Group>) groups
words pronounced together; pauses are defined separately
(<https://talkbank.org/0info/manuals/CHAT.html#Pause_Marker>). The manual
does not state the exclusion in so many words; it follows from what a group
asserts, and chatter enforces it as a structural rule.
