# E701: Per-speaker start-time not monotonically increasing

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

## Description

Each selected utterance bullet must start at or after the previous selected
bullet for the same speaker. Selection prefers an explicit final bullet and
otherwise uses the first top-level internal bullet. Untimed utterances are
skipped; intervening other speakers do not reset the speaker's prior start.

E701 is per-speaker, whereas the separate E362 document-order check compares
explicit final bullets regardless of speaker. The retained CHECK 83 parity
case maps to E362; the numeric E701 mapping does not imply identical scope.
