# E706

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## %mor has more items than the main tier has words

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

### Description

The `%mor` tier has more items than the main tier has alignable words:
an extra analysis, or an analysis for material the alignment excludes,
such as a word inside a retrace.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|2;06.|male|||Target_Child|||
*CHI:	want cookie .
%mor:	pro|I v|want n|cookie .
@Comment:	ERROR: Main tier has 2 words but %mor has 3 items (extra pro|I)
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|2;06.|male|||Target_Child|||
@Comment:	Note: Retraces and scoped content don't align
*CHI:	I want [/] need cookie .
%mor:	pro|I v|want v|need n|cookie .
@Comment:	ERROR: "want" is in a retrace [/] scope and shouldn't align
@Comment:	Main tier alignable: I, need, cookie = 3 words (want is excluded by [/])
@Comment:	Mor tier: Should be pro|I v|need n|cookie (3 items + terminator)
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|2;06.|male|||Target_Child|||
@Comment:	Note: Events are non-alignable, like pauses
*CHI:	I &=laugh want cookie .
%mor:	pro|I v|laugh v|want n|cookie .
@Comment:	ERROR: Event &=laugh shouldn't have a mor item (v|laugh is wrong)
@Comment:	Main tier alignable: I, want, cookie = 3 words (events excluded)
@Comment:	Mor tier: Should be pro|I v|want n|cookie (3 items + terminator)
@End
```

#### Example 4

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|2;06.|male|||Target_Child|||
@Comment:	Note: Pauses, events, actions don't align - only words
*CHI:	I (.) want cookie .
%mor:	pro|I v|pause v|want n|cookie .
@Comment:	ERROR: Pause (.) shouldn't have a mor item (v|pause is wrong)
@Comment:	Main tier alignable: I, want, cookie = 3 words (pauses excluded)
@Comment:	Mor tier: Should be pro|I v|want n|cookie (3 items + terminator)
@End
```

### CHAT Rule

One `%mor` item per main-tier word (https://talkbank.org/0info/manuals/CHAT.html#Morphological_Tier); retraced
material is excluded from analysis (https://talkbank.org/0info/manuals/CHAT.html#MorExclude_Scope).

## A clitic becoming an item preserves its word chunk

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

### Description

A space creates a separate MOR item where a tilde attaches a post-clitic. This increases the item count without changing expanded word chunks. Main/MOR item alignment and MOR/GRA chunk alignment are separate requirements.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
@Comment:	Authored MOR/GRA combinations: repeated post-clitics, POS subcategories,
	ordered flat/keyed/multivalue features, Unicode lemmas and a compound lemma.
	The middle turn has four main words and MOR items but seven GRA word chunks,
	including two post-clitics and the terminator. Neighboring turns are sentinels.
*CHI:	start .
%mor:	verb|start .
%gra:	1|0|ROOT 2|1|PUNCT
%com:	before café
*CHI:	we'd've found café icecream .
%mor:	pron:pers|we-Nom-Person=1~aux|have-Tense=Past~aux|have-Mood=Ind-Polarity=Pos verb|find-Past noun|café-Case=Acc noun|ice_cream-PronType=Int,Rel .
%gra:	1|4|NSUBJ 2|4|AUX 3|2|AUX 4|0|ROOT 5|4|OBJ 6|4|OBJ 7|4|PUNCT
%com:	middle naïve
*CHI:	finish .
%mor:	verb|finish .
%gra:	1|0|ROOT 2|1|PUNCT
%com:	after résumé
@End
```
