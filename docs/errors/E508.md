# E508: Empty @Date header (parser)

> ⏳ Planned; This check is documented but not yet enforced by the validator. The error code will not fire until implementation is complete.

**Kind**: Invalidity

**Level**: header

**Status**: ⏳ Planned

## Description

A `@Date` header with no value. This is the parser-side registration of
the defect that the model reports as E516.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Date:	
*CHI:	hello .
@End
```

## CHAT Rule

`@Date` gives the date of the interaction as day-month-year
(https://talkbank.org/0info/manuals/CHAT.html#Date_Header); an empty one gives nothing.
