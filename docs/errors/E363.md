# E363: Postcode without content

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

## Description

A postcode `[+ ...]` after the terminator carries no code: nothing, or only
whitespace, between `[+ ` and `]`.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello . [+  ]
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello . [+ ]
@End
```

### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello . [+ bch]
@End
```

## CHAT Rule

The CHAT manual's "Utterance level error coding (post-codes)" section (18.2
in the current manual, no named anchor; `#_Toc208734963` in the 2026-09-03
build) defines a postcode as `[+ code]` placed after the terminator.
