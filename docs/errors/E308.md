# E308: Undeclared speaker

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

## Description

A structurally usable speaker code on a main tier is absent from the file's
`@Participants` declaration. This is a cross-reference failure, not a claim
that the code's spelling is intrinsically invalid.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CH-I:	hello world .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*MOT:	hello world .
@End
```

### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child, MOT Mother
@ID:	eng|corpus|CHI|||||Target_Child|||
@ID:	eng|corpus|MOT|||||Mother|||
*MOT:	hello world .
@End
```

## CHAT Rule

The CHAT manual says `@Participants` is obligatory and lists all speakers in
the file:
<https://talkbank.org/0info/manuals/CHAT.html#Participants_Header>. Main-tier
speaker IDs identify which listed participant produced each utterance:
<https://talkbank.org/0info/manuals/CHAT.html#Utterance_Speaker_Code>.
