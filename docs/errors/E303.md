# E303: Header colon not followed by a TAB

> ⏳ Planned; This check is documented but not yet enforced by the validator. The error code will not fire until implementation is complete.

**Kind**: Invalidity

**Level**: file

**Status**: ⏳ Planned

## Description

A header line's colon is followed by something other than a single TAB: a
space, nothing at all, or the value run straight on. CHAT separates a header
name from its value with exactly one TAB, and a header that does not is not a
header the grammar can read.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Situation: at home
*CHI:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:note
*CHI:	hello .
@End
```

### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Situation:	at home
@Comment:	a note
*CHI:	hello .
@End
```

## CHAT Rule

The CHAT manual's "File Headers" section defines every header as `@Name:`
followed by a tab and the value:
<https://talkbank.org/0info/manuals/CHAT.html#File_Headers>. CLAN CHECK
reports the same defect as its error 8 ("Expected @, %, *, TAB").
