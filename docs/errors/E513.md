# E513: Participant entry without a role

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

A `@Participants` entry has a speaker code but no role.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Ruth Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

## CHAT Rule

Each entry is `XXX Name Role`; "participants are identified by three
elements: their speaker ID, their name and their role"
(https://talkbank.org/0info/manuals/CHAT.html#Participants_Header). The name is optional in practice; the role is
not.
