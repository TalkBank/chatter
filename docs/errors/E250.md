# E250: Secondary stress without primary stress

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

## Description

A word carries secondary stress (`ˌ`) but no primary stress (`ˈ`). Secondary
stress is relative to the word's primary stress and cannot be the only stress
level represented in that word.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	ERROR: Secondary stress requires primary stress
@Comment:	Invalid: 'ˌhello' - Secondary stress without primary
*CHI:	ˌhello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	ˌbaˈna:nas .
@End
```

## CHAT Rule

The CHAT manual, section 9.9, “Prosody Within Words,” defines distinct primary
and secondary stress markers and illustrates secondary stress together with
primary stress in `ˌbaˈna:nas`:
<https://talkbank.org/0info/manuals/CHAT.html#SecondaryStress_Element>. The
manual does not state a separate dependency diagnostic; E250 is chatter's
additional structural invariant that secondary stress is not recorded without
primary stress in the same word.
