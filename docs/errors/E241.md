# E241

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Illegal Untranscribed Marker 'xx'

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

### Description

The marker 'xx' is used for untranscribed speech, but this is not allowed in CHAT. The correct marker for untranscribed speech is 'xxx' (three x's).

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I said xx today .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@Options:	CA
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I said xx today .
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I said xx today .
*CHI:	hello .
%mor no_tab_separator
@End
```

### CHAT Rule

Untranscribed speech must be marked with 'xxx' (three x's). Single 'x' represents a single unintelligible phoneme, 'xx' is not a valid CHAT marker. Use 'xxx' for untranscribed speech segments.

## Marker spelling and source boundaries

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

### Description

Marker spelling applies to orthographic word material, not comment text or
sound material. The invalid spelling example samples shortened and miscased
forms in each category; its repair must equal the canonical control without
rewriting the ordinary dependent comment tier.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I said xxx yyy www xxx yyy www today .
%com:	quoted markers xx YY wW XXX YyY WWw remain unchanged
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I said xx YY wW XXX YyY WWw today .
%com:	quoted markers xx YY wW XXX YyY WWw remain unchanged
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I said 0xx (yy) today .
%com:	quoted markers xx YY wW XXX YyY WWw remain unchanged
@End
```

#### Example 4

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I said &~xx &=YY today .
%com:	quoted markers xx YY wW XXX YyY WWw remain unchanged
@End
```

### CHAT Rule

Use the canonical untranscribed marker spelling. A whole-word replacement must
not discard omission or shortening notation: those cases retain E241 but are
not admitted by the simple marker-spelling repair. Marker classification has
one model owner; the repair does not define another vocabulary.
