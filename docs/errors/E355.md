# E355: InterleavedScopedAnnotations

> ✅ Active (requires `--strict-linkers`); This check is active in the validator, but only when `--strict-linkers` is enabled. A validation run with the default rules does not report it.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active (requires `--strict-linkers`)

## Description

An other-completion linker (`++`) was used but the preceding utterance is
from the **same** speaker. The `++` linker is for other-completion
(completing a different speaker's utterance). To complete one's own
utterance, use `+,` (self-completion) instead.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|test|CHI||male|||Target_Child|||
*CHI:	I was going +...
*CHI:	++ to say hello .
@End
```
