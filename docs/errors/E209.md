# E209

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Word has no spoken content

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

### Description

A word on the main tier consists entirely of shortening notation `(text)` with
no actual spoken material. In standard CHAT, `(the)` means the sounds were omitted; it
is not the same as the word being spoken. To mark an omitted word, use
`0the` (zero-word) instead.

In CA mode, a single standalone parenthesized word is instead normalized to a
CA omission with spoken text. Chatter does not extend that interpretation to
two adjacent shortenings such as `(a)(b)`. The paired examples in
`E209_ca_shortening.md` record this distinction for main-tier and replacement
words. CHECK accepts those double-shortening examples; E209 is therefore not
a blanket equivalence to CHECK 155 across modes and source shapes.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	(the) dog .
@End
```

### CHAT Rule

See CHAT manual on shortening and zero-words:
<https://talkbank.org/0info/manuals/CHAT.html>

In standard CHAT, shortening `(text)` represents omitted sounds within a spoken word (e.g.,
`(be)cause`). A standalone shortening with no surrounding spoken material is
semantically empty, the speaker produced no sound for this word.

## CA omission versus adjacent shortenings

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

### Description

In CA mode a single standalone parenthesized word is interpreted as a CA
omission, with spoken text in the model. Inserting `)(` between its letters
produces two adjacent shortenings instead. Neither contributes spoken material,
and the combination is not a single CA omission. The same distinction applies
to words inside replacement annotations; enclosing syntax does not supply
missing spoken content.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@Options:	CA
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	(ab) .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@Options:	CA
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	(a)(b) .
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@Options:	CA
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	word [: (ab)] .
@End
```

#### Example 4

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@Options:	CA
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	word [: (a)(b)] .
@End
```

### CHAT Rule

The CA-omission interpretation applies to a single parenthesized word, not an
arbitrary sequence of shortening elements. Ordinary shortenings need spoken
material elsewhere in the word. These pairs vary only the internal boundary;
the file's CA option and surrounding annotation remain fixed.

## Markers do not combine adjacent shortenings into one CA omission

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

### Description

Under CA mode exactly one shortening with nonlexical markers normalizes to a CA omission. Splitting it into two adjacent shortenings does not. Overlap and paired prosodic markers are preserved on both sides of each control; they cannot supply the missing spoken material. This extends the existing single-versus-two-shortening rule without changing normalization.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
*SPK:	⌈(ma)(ybe) (soon)⌉ .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
*SPK:	⌈(maybe) (soon)⌉ .
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
*SPK:	⌈(la)(ter)⌉ .
@End
```

#### Example 4

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
*SPK:	⌈(later)⌉ .
@End
```

#### Example 5

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
*SPK:	∆(ne)(ar) (far)∆ .
@End
```

#### Example 6

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
*SPK:	∆(near) (far)∆ .
@End
```

### CHAT Rule

These controls extend the existing E209 policy to independently authored word-feature combinations. The paired examples change only the described word or annotation; other source bytes and file options remain fixed.

## Spoken material in shortened words with other features

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

### Description

These independently authored controls combine shortening with repeated omitted
segments, form and language suffixes, replacement annotations and lengthening.
The letters are synthetic controls, not excerpts or renamed corpus utterances.
The corresponding reference file reuses these combinations in one valid
document so source-coordinate, wire and transformation contracts consume them.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	ca(f)é(s) (a)mi(go) (a)mi(g)o ca(f)é(s)ito .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	chir(p)@o (bu)ba@b ca(f)é@c .
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng, spa
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	say pla(n)@s (a)migo@s ami(g)o@s .
@End
```

#### Example 4

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	chir(p)@o [: chirp] ca(f)é [: café] (a)migo [: amigo] .
@End
```

#### Example 5

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	ca:(fé) (a)ga:in ca(f)é: .
@End
```

#### Example 6

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	(chirp)@o .
@End
```

#### Example 7

```chat
@UTF8
@Begin
@Languages:	eng, spa
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	say (amigo)@s .
@End
```

### CHAT Rule

Outside CA mode, shortening records omitted sounds. Only the remaining spoken
segments supply spoken material; neither a form nor a language suffix can do
so. Removing those segments therefore preserves the typed suffix but violates
E209. The existing E203 specs separately cover markers embedded inside a
shortening; the existing E246 specs cover lengthening without prior spoken text.
These controls do not change either policy or the CA-omission interpretation.
