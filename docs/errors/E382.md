# E382: %mor tier parse failure

> ⏳ Planned; This check is documented but not yet enforced by the validator. The error code will not fire until implementation is complete.

**Kind**: Invalidity

**Level**: tier

**Status**: ⏳ Planned

## Description

A `%mor` tier whose content does not parse as morphological items
(`pos|stem` with optional affixes, one per main-tier word).

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello world .
%mor:	|hello n|world .
@End
```

## CHAT Rule

The `%mor` tier's item format is defined in the manual's dependent-tier
chapter (https://talkbank.org/0info/manuals/CHAT.html#Dependent_Tiers) and in the MOR documentation; a `%mor` line
has one item per word, `pos|stem` with affix codes.
