# E245

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Stress marker without following spoken material

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

### Description

A primary stress marker (`ˈ`) or secondary stress marker appears at the start
of a word but is not followed by any spoken material. The marker has nothing
to attach to.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	ˈ .
@End
```

### CHAT Rule

See CHAT manual sections on stress markers and word-level syntax:
<https://talkbank.org/0info/manuals/CHAT.html>

## Marker-only word rejection retains surrounding turns

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A word containing stress markers but no spoken material is rejected by the
existing E245 parser rule. The same file still contains its native neighboring
main/dependent tiers and the target terminator. No empty or invented Word may
replace the rejected carrier. Primary and secondary stress policy is unchanged.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@ID:	eng|sample|SPK|||||Speaker|||
@Comment:	Préface café
*SPK:	café ready .
%com:	opening note
*SPK:	river .
*SPK:	&-hm cedar .

*SPK:	<ash elm> [!] .
*SPK:	ˈbirch .

*SPK:	finch steady ?
%com:	closing note
@End
```

## Secondary stress needs spoken material

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

### Description

The existing E245 rule applies to secondary as well as primary stress. The legal control has both stress levels, satisfying E250. Removing all spoken segments preserves those markers but leaves a marker-only word, rejected during parsing before a fabricated zero-content Word can enter validation. Recovery is not a valid or byte-exact control.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
*SPK:	ˈˌ .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
*SPK:	ˈriˌver .
@End
```

### CHAT Rule

These controls extend the existing E245 policy to independently authored word-feature combinations. The paired examples change only the described word or annotation; other source bytes and file options remain fixed.
