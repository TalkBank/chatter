# E210: Deprecated, replaced by E387

> deprecated

**Kind**: Invalidity

**Level**: word

**Status**: deprecated

## Description

**Deprecated.** This error code was replaced by E387 (`ReplacementOnFragment`).
The validation logic now emits E387 instead of E210 for the same condition.
