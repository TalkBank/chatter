# E524: @Birth for an unknown participant

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

A `@Birth of XXX` header names a speaker code that `@Participants` does
not declare.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Ruth Target_Child
@ID:	eng|corpus|CHI|2;06.00||||Target_Child|||
@Birth of MOT:	01-JAN-2000
*CHI:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Birth of CHI:	01-JAN-2020
*CHI:	hello .
@End
```

## CHAT Rule

`@Birth of #` is a participant-specific header, one of those that "follow
the @ID headers" for a declared participant (https://talkbank.org/0info/manuals/CHAT.html#Birth_Header).
