# E602: Malformed dependent tier header

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

A line begins with `%` but is not a dependent tier header: the colon is
missing, or the colon is not followed by a tab.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
%mor
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
%com: a note
@End
```

### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
%com:	a note
@End
```

## CHAT Rule

"Each dependent tier begins with the percent symbol, a three-letter code,
a colon and a tab" (https://talkbank.org/0info/manuals/CHAT.html#Dependent_Tiers).
