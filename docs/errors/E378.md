# E378: A retracing marker over material with no words

> ✅ Active; This check is active in the validator.

**Severity**: error

**Status**: ✅ Active

## Description

A retracing marker ([/], [//], [///], [/-]) applied to material that contains no words. A marker retraces the WORDS immediately to its left, and a laugh is not a word, so there is nothing for it to refer to.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	ERROR: a laugh is not a word, so the marker retraces nothing
*CHI:	&=laughs [//] water .
@End
```
