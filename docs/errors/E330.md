# E330: Internal CST traversal failure

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

## Description

The parser's typed walk over the concrete syntax tree met something it could
not decode or dispatch: a node whose text is not valid UTF-8, or a node kind
the typed dispatcher for a dependent tier did not expect. This is an
internal invariant, not a property of the CHAT text.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	<hello [/] .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	<hello world> [/] hello world .
@End
```

## CHAT Rule

None: there is no CHAT construct this code judges. The retrace group in the
example is governed by the "Retracing" scoped symbols
(<https://talkbank.org/0info/manuals/CHAT.html#Retracing_Scope>), whose
unclosed form is E316's business.
