# E750

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Space inside angle-bracket group delimiters

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A space directly after the opening `<` or directly before the closing
`>` of an angle-bracket group (`< dog>` or `<dog >`) is invalid (CLAN
CHECK error 160, "Space character is not allowed after '<' or before
'>' character.", check.cpp 4300/4306). The grammar tolerates the
whitespace as an explicit optional `whitespaces` CST node so the parse
recovers, but the construct is invalid CHAT; before this rule the
parser silently DROPPED that whitespace, so accepted files were also
being silently rewritten on normalize.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	< dog> [/] dog .
@Comment:	ERROR: space directly after the opening angle bracket
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	<dog > [/] dog .
@Comment:	ERROR: space directly before the closing angle bracket
@End
```

### CHAT Rule

Group delimiters hug their content. Parity entry:
`crates/talkbank-parser-tests/tests/check_parity/manifest.json`
CHECK 160.

## Complete annotated-group edge whitespace

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

These controls and error variants exercise complete whitespace runs at both
edges of annotated groups, including nested groups. Each E750 finding owns
one edge run, not intervening word separators or annotation spacing.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	<dog> [/] dog .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	<   dog   > [/] dog .
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	< < dog > [!] cat > [/] dog .
@End
```

#### Example 4

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	<<dog> [!] cat> [/] dog .
@End
```

### CHAT Rule

Angle delimiters hug their content. A repair may delete the complete offending
space token at the group's content boundary; it must preserve every spoken
word, nested delimiter, annotation and interior separator.
