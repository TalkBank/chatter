# E314: Incomplete annotation

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

## Description

A scoped annotation is opened with `[` and never given a body or a closing
`]`, so there is no annotation to attach to the preceding word.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	word [
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	word [= a comment] .
@End
```

## CHAT Rule

Scoped symbols are square-bracketed codes with a body, closed before the next
word: <https://talkbank.org/0info/manuals/CHAT.html#Scoped_Symbols>.
