# E360: Invalid media bullet

> ⏳ Planned; This check is documented but not yet enforced by the validator. The error code will not fire until implementation is complete.

**Kind**: Invalidity

**Level**: utterance

**Status**: ⏳ Planned

## Description

A media bullet the parser can recognize as a bullet but not accept: the
registered meaning covers malformed timestamp content and the deprecated
skip form `start_end-`.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello . 357000_357477-
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello . 0_0
@End
```

## CHAT Rule

Bullets are `\u0015start_end\u0015`, two millisecond counts
(https://talkbank.org/0info/manuals/CHAT.html#TimeAlignment_Scope); the skip variant with a trailing dash is no
longer supported.
