## Invalid media bullet

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance, tier

**Status**: ✅ Active

### Description

A media bullet the parser recognizes but cannot accept, including timestamp
overflow and an all-zero inline dependent-tier timestamp pair. Malformed text
that never becomes a structured bullet can instead produce syntax diagnostics.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello . 357000_357477-
@End
```

### CHAT Rule

Bullets are `\u0015start_end\u0015`, two millisecond counts
(https://talkbank.org/0info/manuals/CHAT.html#TimeAlignment_Scope); the skip variant with a trailing dash is no
longer supported.

## Rejected terminal bullets retain their source owner

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

The structured terminal bullet rejects unsupported legacy skip notation and timestamp overflow. Rejection does not authorize invented timing or removal of healthy surrounding turns, dependent notes or final postcodes.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@ID:	eng|sample|SPK|||||Speaker|||
@Media:	body-ending-controls, audio
@Comment:	Préface café
*SPK:	café opening .
%com:	opening note
*SPK:	alder cedar . [+ bch] [+ first] 100_200
%com:	begin note
*SPK:	anchor maple drift ? [+ second] 200_300
%com:	middle note
*SPK:	willow pine . [+ third] 300_400
%com:	tail note
*SPK:	<moss <larch elm> [!]> [!] ! [+ fourth] 400_500
%com:	nested note
*SPK:	hazel . [+ fifth] [+ final] 500_600
%com:	ending note
*SPK:	finch closing .
%com:	closing note
@End
```
