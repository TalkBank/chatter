# E525: Unknown header

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

Chatter cannot admit a header name into its supported model. This includes
invented names and the grammar-recognized but unsupported `@Thumbnail` form.
Free text belongs in `@Comment` or `@Situation`, not under an invented name.
Recognizing a name in the grammar does not by itself implement its semantics.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@UnknownHeader:	this header does not exist
*CHI:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	anything at all
@Situation:	at home
*CHI:	hello .
@End
```

### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Page:	anything at all
*CHI:	hello .
@End
```

### Example 4

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Thumbnail:	anything at all
@Situation:	at home
*CHI:	hello .
@End
```

## CHAT Rule

See the CHAT manual's "File Headers" chapter for format background:
<https://talkbank.org/0info/manuals/CHAT.html#File_Headers>. Chatter reports
unsupported names explicitly instead of inventing a header meaning. Legacy
`@Page` syntax is rejected by the grammar as E316, as the subsumption control
records; it does not additionally require E525.
