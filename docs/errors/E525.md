# E525: Unknown header

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

Chatter cannot admit a header name into its supported model. This includes
invented names and the grammar-recognized but unsupported `@Thumbnail` form.
Free text belongs in `@Comment` or `@Situation`, not under an invented name.
Recognizing a name in the grammar does not by itself implement its semantics.

## Examples

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@UnknownHeader:	this header does not exist
*CHI:	hello .
@End
```

## CHAT Rule

See the CHAT manual's "File Headers" chapter for format background:
<https://talkbank.org/0info/manuals/CHAT.html#File_Headers>. Chatter reports
unsupported names explicitly instead of inventing a header meaning. The
`@Page` control has a nonnumeric payload and is rejected as E316 by the
`page_number` grammar rule (`[0-9]+`); it does not additionally require E525.
This control must not be used to classify the supported header name as unknown.
