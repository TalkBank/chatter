# E525: Unknown header

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

A line begins with `@` and a name that is not a CHAT header. Modern CHAT has
a closed set of headers and no "soft" kinds; free text belongs in
`@Comment` or `@Situation`, not under an invented name.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@UnknownHeader:	this header does not exist
*CHI:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	anything at all
@Situation:	at home
*CHI:	hello .
@End
```

## CHAT Rule

The CHAT manual's "File Headers" chapter is the closed list:
<https://talkbank.org/0info/manuals/CHAT.html#File_Headers>. A legacy
`@Page` header is reported under this code too, with its own message.
