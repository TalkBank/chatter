# E533: Empty @Options header

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

An `@Options` header with no option named.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@Options:	
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@Options:	CA
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

## CHAT Rule

`@Options` "is not obligatory ... when it occurs, it must follow the
@Participants line" and names options whose spelling is case-sensitive
(https://talkbank.org/0info/manuals/CHAT.html#Options_Header).
