# E530: Lazy gem inside a begin/end scope

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

A lazy gem header `@G` appears while a `@Bg` scope is open. Lazy gems
define a flat series (each runs to the next `@G`); an explicit scope around
one has no defined meaning.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Bg:	activity
@Comment:	inside a Bg/Eg scope
@G:	playing with blocks
@Eg:	activity
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@G:	snack
*CHI:	hello .
@G:	play
*CHI:	hi .
@End
```

## CHAT Rule

The CHAT manual's `@Bg` and `@Eg` headers
(<https://talkbank.org/0info/manuals/CHAT.html#Bg_Header>,
<https://talkbank.org/0info/manuals/CHAT.html#Eg_Header>): each `@Bg` must
have a matching `@Eg`, and when the colon form is used the text after `@Eg:`
must exactly match the corresponding `@Bg:`. One pair may be nested inside
another, but "double embedding is not allowed". The lazy form `@G`
(<https://talkbank.org/0info/manuals/CHAT.html#G_Header>) marks gems that
neither nest nor overlap, each running to the next `@G`.
