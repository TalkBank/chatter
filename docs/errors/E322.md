# E322: EmptyColon

> ⏳ Planned; This check is documented but not yet enforced by the validator. The error code will not fire until implementation is complete.

**Kind**: Invalidity

**Level**: utterance

**Status**: ⏳ Planned

## Description

This diagnostic represents a main-tier prefix with a zero-width (MISSING)
colon node. A missing colon in source does not necessarily produce that node:
the retained deletion examples instead produce ERROR recovery and E316.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|test|CHI||female|||Target_Child|||
*CHI hello .
@End
```
