# E757: Bracketed code glued to the following content

> ✅ Active; This check is active in the validator.

**Severity**: error

**Status**: ✅ Active

## Description

A bracketed code's closing ] directly attached to the start of the next word with no space (hello [/]x, hello [!]x) is invalid (CLAN CHECK error 19, "Illegal use of delimiter in a word." / "Or a SPACE should be added after it.").

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello [/]x .
@Comment:	ERROR: the retrace code is glued to the following word
@End
```
