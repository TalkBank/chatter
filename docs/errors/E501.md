## Duplicate single-occurrence header

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header, file

**Status**: ✅ Active

### Description

A header that a file may carry only once appears twice: `@UTF8`, `@Begin`,
`@End`, `@Languages`, `@Media`, `@Videos` or `@Types`.
This is an occurrence rule, not a claim that the repeated values are identical.
Conflicting declarations require establishing the intended information; the
diagnostic alone cannot determine which declaration should be retained.

### CHAT Rule

The CHAT manual's "File Headers" chapter defines `@UTF8`, `@Begin` and
`@End` as the fixed frame of a file (https://talkbank.org/0info/manuals/CHAT.html#File_Headers, https://talkbank.org/0info/manuals/CHAT.html#Begin_Header,
https://talkbank.org/0info/manuals/CHAT.html#End_Header) and `@Media` as one header per file (https://talkbank.org/0info/manuals/CHAT.html#Media_Header).

## Duplicate headers remain diagnosable during unrelated recovery

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: file

**Status**: ✅ Active

### Description

A malformed utterance does not make duplicate structured headers permissible.
The diagnostic and a safe repair are different obligations: reporting a known
duplicate does not certify that a document requiring grammar recovery can be
rewritten automatically.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello ] .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello ] .
@End
```

### CHAT Rule

Use one `@Languages` declaration and balanced main-tier syntax. Repair the
unmatched bracket using the intended utterance; do not guess its missing mate.
