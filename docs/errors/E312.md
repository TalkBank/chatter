# E312: Unclosed bracket

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

## Description

Opening bracket `[` on the main tier has no matching closing bracket `]`.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	word [= comment .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	<hello[,> [!] .
@End
```

## CHAT Rule

See CHAT manual on annotation brackets. All bracket notation must be
properly opened and closed: `[= comment]`, `[: replacement]`, etc.
