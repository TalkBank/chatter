# E312: Unclosed bracket

> ⏳ Planned; This check is documented but not yet enforced by the validator. The error code will not fire until implementation is complete.

**Kind**: Invalidity

**Level**: utterance

**Status**: ⏳ Planned

## Description

Opening bracket `[` on the main tier has no matching closing bracket `]`.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	word [= comment .
@End
```

## CHAT Rule

See CHAT manual on annotation brackets. All bracket notation must be
properly opened and closed: `[= comment]`, `[: replacement]`, etc.
