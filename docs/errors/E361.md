# E361: Invalid bullet timestamp

> ⏳ Planned; This check is documented but not yet enforced by the validator. The error code will not fire until implementation is complete.

**Kind**: Invalidity

**Level**: utterance

**Status**: ⏳ Planned

## Description

A media bullet `\u0015START_END\u0015` whose start or end is not a
millisecond count.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Media:	sample, audio
*CHI:	hello . abc_def
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Media:	sample, audio
*CHI:	hello . 500_1000
@End
```

## CHAT Rule

The CHAT manual's "Time Alignment" scope defines the bullet as two
millisecond counts separated by an underscore, between two U+0015
delimiters, after the terminator and any postcodes:
<https://talkbank.org/0info/manuals/CHAT.html#TimeAlignment_Scope>,
<https://talkbank.org/0info/manuals/CHAT.html#Utterance_Media>.
