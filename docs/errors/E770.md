# E770: Timing bullet before utterance material

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

## Description

A main-tier timing bullet needs preceding utterance material. Later speech
cannot provide a backward scope for a bullet already encountered. The explicit
nonverbal zero, events, actions and pauses supply material; linkers, precodes,
and structural markers do not. Traverse nested groups in source order.

## CHAT Rule

The CHAT manual's Audio and Video Time Marks section scopes timing markers to
preceding material: <https://talkbank.org/0info/manuals/CHAT.html#Media_Linking>.
CHECK 73's leading-bullet case corroborates the missing backward scope. This
rule does not copy CHECK's separate legacy multi-bullet option policy and does
not decide empty scopes between later bullets.
