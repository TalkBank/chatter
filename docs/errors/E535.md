# E535: Unsupported @Media Type

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header, file

**Status**: ✅ Active

## Description

An `@Media` header contains a media type that is not one of the recognized values. The file parses successfully but the unsupported type is stored as `Unsupported(String)` and flagged during validation.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Media:	recording, badtype
*CHI:	hello world .
@End
```

### Example 2

```chat

@Begin
@Languages:	eng

@Media:	recording, audio
*CHI:	hello world .100_200
```

## CHAT Rule

The `@Media` header accepts media types: `audio`, `video`, `missing`. Any other type value is flagged as unsupported.

Reference: <https://talkbank.org/0info/manuals/CHAT.html#Media_Header>

CHECK 21-Sep-2026 reports 114 for the type-deletion mutation. After scanning
media-header tokens, `check.cpp:5622–5624` reports that error when neither its
audio nor video flag was set. The control and mutation also receive the
independent basename-mismatch error 157 in the named fixture run; that does
not account for the mutation's additional 114. This grounds the shared
rejection of an absent media type, not every boundary of CHECK's flag policy.
