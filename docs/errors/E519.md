# E519: Invalid language code or undeclared ID language

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word, utterance, header

**Status**: ✅ Active

## Description

A language code that is not in the ISO 639-3 registry, wherever a language
code appears: the `@Languages` header, the language field of `@ID`, an
`@L1 of` header, or a word-level switch (`word@s:CODE`). The placeholder
`xxx` is not a language either.

Every member of a mixed (`@s:spa+fra`) or ambiguous (`@s:spa&fra`)
marker must be a real code. Ambiguity concerns which language applies, not
whether its names are valid. The paired examples replace one valid code with
`qzz`, including either position in an ambiguous pair. None of these word-level
codes needs a declaration in `@Languages`.

E519 also reports an `@ID` language absent from `@Languages`, even when the
code itself is registry-valid (CHECK 122). This cross-header requirement does
not apply to a word-level switch. The paired examples repair the mismatch by
either changing the ID field or extending the multilingual declaration.

Shape is checked independently of registry membership: `en` is not the
three-letter code required here; use `eng` (CHECK 120). The paired example
changes both header occurrences so the language-declaration relationship
stays consistent while isolating the code-length defect.

## CHAT Rule

"The language codes come from the international ISO 639-3 standard"
(<https://talkbank.org/0info/manuals/CHAT.html#Languages_Header>); the same
codes fill the `@ID` language field
(<https://talkbank.org/0info/manuals/CHAT.html#ID_Header>) and the `@L1 of`
header (<https://talkbank.org/0info/manuals/CHAT.html#L1_Header>), and mark
word-level switches (`@s:` in the special-form markers,
<https://talkbank.org/0info/manuals/CHAT.html#Special_Form_Markers>).
