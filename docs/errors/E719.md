# E719: %sin has more tokens than the main tier has words

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

The `%sin` (sign) tier has more tokens than the main tier has alignable
words.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|2;06.|male|||Target_Child|||
*CHI:	want cookie .
%sin:	POINT REACH GRAB
@Comment:	ERROR: Main tier has 2 words but %sin has 3 tokens (extra GRAB)
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	want cookie .
%sin:	REACH GRAB
@End
```

## CHAT Rule

The `%sin` tier gives a sign for each word of the main tier
(https://talkbank.org/0info/manuals/CHAT.html#Sign_Tier).
