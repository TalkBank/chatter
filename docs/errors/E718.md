# E718: %sin has fewer tokens than the main tier has words

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

The `%sin` (sign) tier has fewer tokens than the main tier has alignable
words, so some words have no sign token.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|2;06.|male|||Target_Child|||
*CHI:	I want cookie .
%sin:	POINT REACH
@Comment:	ERROR: Main tier has 3 words but %sin only has 2 tokens (missing gesture for cookie)
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I want cookie .
%sin:	POINT REACH GRAB
@End
```

## CHAT Rule

The `%sin` tier gives a sign for each word of the main tier
(https://talkbank.org/0info/manuals/CHAT.html#Sign_Tier).
