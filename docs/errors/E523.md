# E523: Orphan @ID header

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

An `@ID` line names a speaker code that `@Participants` does not declare.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Ruth Target_Child
@ID:	eng|corpus|CHI|2;06.00||||Target_Child|||
@ID:	eng|corpus|MOT|||||Mother|||
*CHI:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child, MOT Mother
@ID:	eng|corpus|CHI|||||Target_Child|||
@ID:	eng|corpus|MOT|||||Mother|||
*CHI:	hello .
@End
```

## CHAT Rule

"There must be one @ID field for each participant" (https://talkbank.org/0info/manuals/CHAT.html#ID_Header), and
`@Participants` "lists all of the speakers within the file"
(https://talkbank.org/0info/manuals/CHAT.html#Participants_Header).
