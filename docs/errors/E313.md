# E313: Unclosed parenthesis

> deprecated

**Kind**: Invalidity

**Level**: utterance

**Status**: deprecated

## Description

The former classifier searched recovery text for an opening parenthesis
without a closing parenthesis. That does not establish a parsed shortening or
pause. E313 has no live producer and is deprecated.

The malformed examples remain rejected through E316; the balanced
noncompletion control remains legal. Direct canonical-fixture regression tests
retain all three boundaries despite the deprecated-code spec deferral.
A grammar-produced MISSING token still has its own recovery diagnostic;
typed word validation is separate from ERROR-text classification.
