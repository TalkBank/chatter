# E702: %mor item without a separator

> ⏳ Planned; This check is documented but not yet enforced by the validator. The error code will not fire until implementation is complete.

**Kind**: Invalidity

**Level**: tier

**Status**: ⏳ Planned

## Description

A `%mor` item with no `|` between its part of speech and its stem, so
neither field can be told from the other.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello world .
%mor:	hello n|world .
@End
```

## CHAT Rule

`%mor` items are `pos|stem` with optional prefix, suffix and translation
fields (https://talkbank.org/0info/manuals/CHAT.html#MOR_Format).
