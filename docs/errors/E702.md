# E702: Unparsable content in a %mor item

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

A `%mor` item with no `|` between its part of speech and its stem, so
neither field can be told from the other.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello world .
%mor:	hello n|world .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello .
%mor:	co| .
@End
```

## CHAT Rule

`%mor` items are `pos|stem` with optional prefix, suffix and translation
fields (https://talkbank.org/0info/manuals/CHAT.html#MOR_Format).
