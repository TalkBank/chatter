# E767: whitespace before the comma in @Media

> ✅ Active; This check is active in the validator.

**Severity**: error

**Status**: ✅ Active

## Description

In @Media the comma separates the filename from the media type, and the filename ends where the comma begins:

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Media:	SD02_recording , audio
*CHI:	hello .
@Comment:	ERROR: the filename ends where the comma begins
@End
```
