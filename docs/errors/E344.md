# E344: Quotation-precedes terminator without a quoted linker

> ⏳ Planned; This check is documented but not yet enforced by the validator. The error code will not fire until implementation is complete.

**Kind**: Invalidity

**Level**: utterance

**Status**: ⏳ Planned

## Description

An utterance ends with the quotation-precedes terminator `+".`, which says
"the quotation came BEFORE this", but no earlier utterance by the same
speaker was marked as the quotation with the `+"` linker.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child, MOT Mother
@ID:	eng|corpus|CHI|||||Target_Child|||
@ID:	eng|corpus|MOT|||||Mother|||
*MOT:	and then he said +".
*CHI:	okay .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child, MOT Mother
@ID:	eng|corpus|CHI|||||Target_Child|||
@ID:	eng|corpus|MOT|||||Mother|||
*MOT:	+" I am going home now .
*MOT:	and then he said +".
*CHI:	okay .
@End
```

## CHAT Rule

The CHAT manual's "Quotation Precedes" terminator `+".` and the "Quoted
Utterance" linker `+"` are defined as a pair:
<https://talkbank.org/0info/manuals/CHAT.html#QuotationPrecedes_Terminator>,
<https://talkbank.org/0info/manuals/CHAT.html#QuotedUtterance_Linker>, under
"Utterance Linkers"
(<https://talkbank.org/0info/manuals/CHAT.html#Utterance_Linkers>).
