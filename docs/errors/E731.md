# E731: Speaker bullet self-overlap via timing

> ⏳ Planned; This check is documented but not yet enforced by the validator. The error code will not fire until implementation is complete.

**Kind**: Invalidity

**Level**: tier

**Status**: ⏳ Planned

## Description

A reserved code for same-speaker bullet overlap. The implemented temporal
E704 check already covers this behavior with a 500 ms tolerance, matching
CHECK 133. E704 also has a separate overlap-marker check. E731 does not
establish an additional zero-tolerance policy.

**Validation not yet implemented for this spec example.** No production
code path constructs this `ErrorCode` variant; the only references in the
workspace before this spec were the CHECK-parity number mapping
(`crates/talkbank-parser-tests/src/check_error_map.rs`) and the reserved
constant `crates/talkbank-model/src/errors/codes/temporal.rs::E731`. The
E704 bullet-timing self-overlap check is the implemented owner.

## CHAT Rule

Corresponds to CLAN CHECK error 133 ("BEG time is smaller than same
speaker's previous END time"). See CHAT manual on media bullets:
<https://talkbank.org/0info/manuals/CHAT.html#Working_with_Media>
