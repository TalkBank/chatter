# E357

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## UnmatchedUnderlineEnd

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

An underline end marker was found without a preceding underline begin
marker in the same utterance. The end marker has no open underline to
close.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	ERROR: Unmatched underline end marker
*CHI:	hello world .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||

@End
```

## Underline opener beside attached CA pitch

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A closing underline marker needs a preceding opening underline marker in
the same utterance. An attached pitch shift is a different typed symbol,
not an underline opener.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
*SPK:	↑rainbow .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
*SPK:	↑rainbow .
@End
```

### CHAT Rule

Keep the `U+0002 U+0001` opening and `U+0002 U+0002` closing pairs balanced
in utterance order, including when underlining covers only part of a word
beside an attached pitch marker. The existing E357 rule applies unchanged.
