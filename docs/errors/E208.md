# E208: Empty replacement

> deprecated

**Kind**: Invalidity

**Level**: word

**Status**: deprecated

## Description

A replacement must contain at least one intended word. Empty `[: ]` syntax is
rejected during parsing, before a replacement can enter the model. E208 is
retained as a historical diagnostic identifier; model validation no longer
needs an empty-collection branch because checked Rust and JSON admission make
that state unrepresentable.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello [: ] .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello [: world] .
@End
```

## CHAT Rule

`[: replacement]` requires one or more intended words after the colon. Supply
the intended words or remove the annotation; an empty alternative conveys no
replacement. See <https://talkbank.org/0info/manuals/CHAT.html#Replacement_Scope>.
