# E242: Unbalanced quotation delimiters

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

## Description

An opening curly double quote (`“`, U+201C) starts a short quotation stretch
inside an utterance. It must be paired with a closing curly double quote (`”`,
U+201D). E242 reports a missing or out-of-order partner within that utterance;
cross-utterance quotation linkers are checked separately.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	ERROR: Quotation delimiters must be balanced
@Comment:	Invalid: opening U+201C has no closing U+201D
*CHI:	“hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello” .
@End
```

### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	TEA Teacher
@ID:	eng|corpus|TEA|||||Teacher|||
*TEA:	“plant” [//] what is “plant” ?
@End
```

## CHAT Rule

The CHAT manual's “Quotation” section defines U+201C as the begin delimiter and
U+201D as the end delimiter for a short quotation stretch inside an utterance:
<https://talkbank.org/0info/manuals/CHAT.html#Quotation>. A quotation stretch
therefore requires the ordered pair rather than an unpaired delimiter.
