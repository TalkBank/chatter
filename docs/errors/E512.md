# E512: Empty participant code

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

A `@Participants` entry with no speaker code.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	Target_Child
*CHI:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

## CHAT Rule

Each `@Participants` entry is `XXX Name Role` (https://talkbank.org/0info/manuals/CHAT.html#Participants_Header).
