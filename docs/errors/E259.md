# E259: Comma after non-spoken content

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word, utterance

**Status**: ✅ Active

## Description

Comma without any preceding spoken word in the utterance

The rule follows document order through nested content. A word later in a
group cannot license an earlier comma. Replacement annotations do not turn an
omitted original word into spoken content.
