# E253: Empty word content

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

## Description

Parser recovery produced a word node whose typed content list is empty. Such a
node does not represent any spoken or annotated word content and cannot be a
valid main-tier item.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	ERROR: Word must have content
@Comment:	Invalid: Empty word element
*CHI:	  .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

## CHAT Rule

The CHAT manual defines the main line primarily as a series of words and a
word as a nonempty series of permitted characters and word-internal markers:
<https://talkbank.org/0info/manuals/CHAT.html#Words>. E253 is chatter's
structural recovery invariant for a word node that contains none of those
items.
