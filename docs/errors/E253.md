# E253: Empty word content

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word, utterance

**Status**: ✅ Active

## Description

An empty word content list has no spoken or annotated word content. E253 also
reports a main tier consisting only of authored separators, which supplies no
word content. A normal nonempty word does not trigger this rule.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	ERROR: Word must have content
@Comment:	Invalid: Empty word element
*CHI:	  .
@End
```

## CHAT Rule

The CHAT manual defines the main line primarily as a series of words and a
word as a nonempty series of permitted characters and word-internal markers:
<https://talkbank.org/0info/manuals/CHAT.html#Words>. E253 is chatter's
structural invariant for a word with none of those items, and also identifies
separator-only utterances with no word content.
