# E756: Empty dependent tier

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Status**: ✅ Active

## Description

A dependent tier whose content is empty or whitespace-only declares nothing: the line asserts an annotation that is not there and fails to make sense.

### Example 1
