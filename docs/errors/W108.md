# W108: Speaker not declared in @Participants (warning form)

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

## Description

A main tier's speaker code is not among the participants the file
declares.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*MOT:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

## CHAT Rule

`@Participants` "lists all of the speakers within the file"
(https://talkbank.org/0info/manuals/CHAT.html#Participants_Header); every main tier names one of them
(https://talkbank.org/0info/manuals/CHAT.html#Utterance_Speaker_Code).
