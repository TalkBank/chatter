# E721: %gra indices not sequential

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

The `%gra` items' own indices do not run 1, 2, 3, ... in order.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I want cookie .
%mor:	pro|I v|want n|cookie .
%gra:	1|3|NSUBJ 3|0|ROOT 2|3|OBJ 4|3|PUNCT
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	I want cookie .
%mor:	pro|I v|want n|cookie .
%gra:	1|2|NSUBJ 2|0|ROOT 3|2|OBJ 4|2|PUNCT
@End
```

## CHAT Rule

Each `%gra` item's first number is the position of its word
(https://talkbank.org/0info/manuals/CHAT.html#GrammaticalRelations_Tier), so the items are numbered in order.
