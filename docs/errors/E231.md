# E231: Unbalanced shortening parenthesis

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

## Description

Shortening parentheses are grammar-owned structure. The two examples retain
the distinct ERROR-node (E316) and missing-token (E342) rejection paths.
Recovered structure is not proof of valid CHAT.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hel(o .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	be(cause.
@End
```
