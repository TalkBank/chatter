# E704

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Speaker self-overlap, overlapping overlap markers

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

### Description

A single speaker has consecutive utterances with overlap markers (`⌈⌉`/`⌊⌋`) that overlap with each other. Overlap markers should indicate simultaneous speech between **different** speakers, not self-overlap.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello ⌈ world ⌉ .
*CHI:	⌊ testing ⌋ .
@End
```

### CHAT Rule

Overlap markers (`⌈⌉` top, `⌊⌋` bottom) indicate simultaneous speech between two different speakers. A speaker cannot overlap with themselves. See CHAT manual section on overlap notation: https://talkbank.org/0info/manuals/CHAT.pdf

## Untranscribed speech constrains same-speaker timing

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

An authored timing matrix compares untranscribed-only turns with lexical
speech. All starts are nondecreasing. The middle turn has a broad timing span;
substituting a lexical word does not change its timing obligation. These
examples are not production attestations.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|sample|CHI|||||Target_Child|||
@Media:	E704_untranscribed_timing_1, audio
*CHI:	hello . 1000_2000
*CHI:	www . 1500_9000
*CHI:	world . 2000_3000
@End
```

### CHAT Rule

All timed speech constrains the same speaker's following turn, with a 500 ms
tolerance. Untranscribed or unintelligible speech still occupies time. The
third turn is compared with the middle turn's endpoint, regardless of whether
its words have been transcribed.
