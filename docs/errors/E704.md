# E704

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Speaker self-overlap, overlapping overlap markers

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier, file

**Status**: ✅ Active

### Description

E704 has two independent validation paths:

- **Overlap markers:** adjacent utterances belong to the same speaker; the
  first has a paired top overlap region and the second has a paired bottom
  region. An ordinary continuation without a bottom region is not enough.
- **Media timing:** the current selected utterance bullet starts more than
  500 ms before the same speaker's previous selected bullet ends. Exactly
  500 ms is accepted. This path does not require overlap markers.

The millisecond tolerance belongs only to the timing path. The authored marker
examples do not measure or prove a temporal tolerance.

### CHAT Rule

The marker and temporal contracts are separate. See
[Bullet Validation](../../book/src/architecture/bullet-validation.md) and the
[retained CHECK assessment](../../book/src/architecture/errors-and-validation/check-parity-audit.md)
for their scope. A shared code does not justify rewriting transcription
without reviewing which relationship the diagnostic actually reports.

## Untranscribed speech constrains same-speaker timing

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

An authored timing matrix compares untranscribed-only turns with lexical
speech. All starts are nondecreasing. The middle turn has a broad timing span;
substituting a lexical word does not change its timing obligation. These
examples are not production attestations.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|sample|CHI|||||Target_Child|||
@Media:	E704_untranscribed_timing_1, audio
*CHI:	hello . 1000_2000
*CHI:	www . 1500_9000
*CHI:	world . 2000_3000
@End
```

### CHAT Rule

All timed speech constrains the same speaker's following turn, with a 500 ms
tolerance. Untranscribed or unintelligible speech still occupies time. The
third turn is compared with the middle turn's endpoint, regardless of whether
its words have been transcribed.
