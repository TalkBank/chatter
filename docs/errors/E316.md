# E316: Unparsable content

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance, tier

**Status**: ✅ Active

## Description

The parser could not make a construct of some region of the file, and no
more specific rule claimed it. E316 is the generic verdict: it names the
region and says nothing about which rule was broken, which is exactly why
every specific code's spec records where it is reached instead of E316.

## CHAT Rule

None of its own: E316 is reached when the CHAT manual's grammar, as
chatter implements it, is not met and no narrower rule explains how.
The main-tier example set covers a speaker line without a colon, brace
and angle-bracket garbage, a bullet with its times reversed inside a
postcode, and a `%mor` item without a separator.
