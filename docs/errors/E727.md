# E727: Phoaln tier word count does not match mod tier

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

The effective `%xphoaln` model-side slot count does not match the `%mod`
word count. Actual-only pauses consume no model slot; ordinary lexical
alignment words consume one even if a segment on that side is null.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	nld
@Participants:	CHI Child, MOT Mother
@ID:	nld|corpus|CHI|2;00.||||Child|||
@ID:	nld|corpus|MOT|||||Mother|||
*MOT:	muts ja .
%mod:	ˈmœts ˈja
%xphoaln:	m↔m,œ↔ʉ,t↔s,s↔t
@Comment:	ERROR: %mod has 2 words but %xphoaln has only 1
@End
```

## CHAT Rule

Each lexical alignment word consumes a `%mod` slot. A single-pair pause
present only on the actual side (`∅↔(.)`) consumes no `%mod` slot; its absence
must not shift later words. E727 compares this effective count, not the raw
number of `%xphoaln` entries, against `%mod` (Phon extension spec §2 rule 5).
