# E258

> Several rules are reported under this code. Each section below is a

## Consecutive commas

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance, tier

**Status**: ✅ Active

### Description

Two comma separator items occur consecutively in document order with no
intervening content. CHAT uses one comma for a syntactic break; the two-comma
sequence is not a stronger version of that separator.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello ,, world .
@End
```

### CHAT Rule

The CHAT manual's “Comma” section permits a comma after a word to mark a
syntactic break and requires commas to be space-delimited:
<https://talkbank.org/0info/manuals/CHAT.html#Comma>. CLAN CHECK 107/156
separately rejects repeated literal commas; if `,,` was intended as the
Conversation Analysis tag marker, write the distinct U+201E character (`„`).

## Consecutive commas in a recovered main tier

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

Consecutive typed comma separators remain invalid when another part of their
main tier requires recovery. A diagnostic does not by itself admit its carrier
for a mechanical fix.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello , world ] .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello ,, world ] .
@End
```

### CHAT Rule

Write a single syntactic-break comma and balanced main-tier syntax. Establish
the intended bracket structure before requesting automatic punctuation repairs.
