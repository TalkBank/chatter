# E516: Empty @Date

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

The `@Date` header has no value.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Date:	
*CHI:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Date:	01-JAN-2024
*CHI:	hello .
@End
```

## CHAT Rule

`@Date` gives the date of the interaction as `DD-MMM-YYYY`
(https://talkbank.org/0info/manuals/CHAT.html#Date_Header).
