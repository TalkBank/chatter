# E507: Empty @Languages header

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

The `@Languages` header names no language.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

## CHAT Rule

`@Languages` "tells the programs which language is being used", as one
or more ISO 639-3 codes (https://talkbank.org/0info/manuals/CHAT.html#Languages_Header).
