# E306

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Utterance has no content

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A main tier has a speaker and terminator but no meaningful utterance content
between them. The terminator closes an utterance; it is not itself spoken
content.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	.
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
@End
```

### CHAT Rule

The CHAT manual describes the main line as the transcription of what the
speaker said, beginning after the speaker ID, colon, and tab:
<https://talkbank.org/0info/manuals/CHAT.html#Main_Line>. A bare terminator does
not provide that required utterance content.

## Separator-only turns and dependent-tier ownership

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A separator-only main tier has no meaningful utterance content. Dependent
tiers belong to that turn; their text does not fill its missing speech.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
*CHI:	voice .
%com:	this comment belongs to the second turn
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
*CHI:	, .
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
*CHI:	, .
%com:	this comment belongs to the second turn
@End
```

### CHAT Rule

Supply the missing main-tier content from evidence. Removing an empty turn
is a semantic choice, not an automatic mechanical repair. If dependent tiers
exist, resolving their content and ownership requires a separate decision.
