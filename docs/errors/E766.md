# E766: linker not utterance-initial

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Status**: ✅ Active

## Description

Linkers (+", ++, +<, +^, +,, +≈, +≋) connect an utterance to the PREVIOUS utterance, so they are utterance-initial by definition:

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	yeah that go +" okay .
@Comment:	ERROR: the linker must open the utterance
@End
```
