# E346: Quoted-utterance linker outside a quotation sequence

> ⏳ Planned; This check is documented but not yet enforced by the validator. The error code will not fire until implementation is complete.

**Kind**: Invalidity

**Level**: utterance

**Status**: ⏳ Planned

## Description

An utterance begins with the quoted-utterance linker `+"`, which marks it as
quoted speech, but nothing around it says whose quotation it is: no earlier
same-speaker utterance ended with `+"/.` (quotation follows) and no later
one ends with `+".` (quotation precedes).

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child, MOT Mother
@ID:	eng|corpus|CHI|||||Target_Child|||
@ID:	eng|corpus|MOT|||||Mother|||
*MOT:	+" I am going home now .
*CHI:	okay .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child, MOT Mother
@ID:	eng|corpus|CHI|||||Target_Child|||
@ID:	eng|corpus|MOT|||||Mother|||
*MOT:	he said +"/.
*MOT:	+" I am going home now .
*CHI:	okay .
@End
```

## CHAT Rule

The "Quoted Utterance" linker `+"` continues a quotation announced by the
`+"/.` terminator or closed by the `+".` terminator:
<https://talkbank.org/0info/manuals/CHAT.html#QuotedUtterance_Linker>,
<https://talkbank.org/0info/manuals/CHAT.html#QuotationFollows_Terminator>,
<https://talkbank.org/0info/manuals/CHAT.html#QuotationPrecedes_Terminator>.
