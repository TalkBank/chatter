# E305

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Missing terminator

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

Main tier is missing its required utterance terminator.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello world
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello world .
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@Options:	CA
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello world
@End
```

### CHAT Rule

The CHAT manual's “Basic Utterance Terminators” section requires one utterance
per main line and requires ordinary CHAT utterances to end in `.`, `?`, or `!`:
<https://talkbank.org/0info/manuals/CHAT.html#Utterance_Terminator>. Its
`@Options` section documents that `@Options: CA` removes the usual terminator
requirement for Conversation Analysis transcription:
<https://talkbank.org/0info/manuals/CHAT.html#Options_Header>.

## Missing terminator does not discard timing evidence

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A missing terminator does not authorize deletion of timing evidence. Internal
bullets, and a distinct grammar-routed terminal bullet when present, must retain
their values and source order in the model and serialized output.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Media:	bullet-retention, audio
*CHI:	hello 100_200 . 200_300
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Media:	bullet-retention, audio
*CHI:	hello 100_200 200_300
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Media:	bullet-retention, audio
*CHI:	hello 100_200 .
@End
```

#### Example 4

```chat

@Options:	multi
@ID:	eng|corpus|CHI|||||Target_Child|||

@End
```

#### Example 5

```chat

@ID:	eng|corpus|CHI|||||Target_Child|||
```

#### Example 6

```chat

@ID:	eng|corpus|CHI|||||Target_Child|||
@Media:	bullet-retention, audio

```

#### Example 7

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child

@Media:	bullet-retention, audio
```

### CHAT Rule

E305 requires the ordinary utterance terminator. The legal controls assert only
that this rule is satisfied; they do not adjudicate every placement policy for
internal bullets. The CHAT manual's Audio and Video Time Marks section assigns
a separate scope to each bullet, so silently collapsing multiple bullets loses
information: <https://talkbank.org/0info/manuals/CHAT.html#Media_Linking>.

## Missing terminator before timing media

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A timing bullet does not replace the main-tier utterance terminator. These
examples retain the timed reference document's dependent tiers, picture and
continuation text. Each invalid variant deletes exactly one typed terminator
from `corpus/reference/content/media-bullets.cha`, retaining surrounding spaces
and all other bytes. The control is that reference document without changes.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child, MOT Mother
@ID:	eng|sample|CHI|2;00.||||Child|||
@ID:	eng|sample|MOT|||||Mother|||
@Media:	media-bullets, video
@Comment:	Inline timing bullets on main tier and dependent tiers, inline_pic
@Comment:	Constructs: inline_bullet, timing_annotation, text_with_bullets,
	text_with_bullets_and_pics, media bullets on dependent tiers, inline_pic
*CHI:	hello there . 2041689_2042652
%cod:	this is junk 2041689_2042652
*MOT:	how are you ? 5041689_5042652
%act:	foo 2061689_2062652 bar 2061689_2062652
%com:	pic002 %pic:"a18/image002.jpg"
@End
```

#### Example 2


### CHAT Rule

Outside Conversation Analysis mode an utterance requires a terminator; the
following timing bullet identifies media alignment rather than punctuation.
See the E305 specification for the terminator rule and its CA exception.
