# E305

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Missing terminator

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

Main tier is missing its required utterance terminator.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello world
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello world .
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@Options:	CA
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello world
@End
```

### CHAT Rule

The CHAT manual's “Basic Utterance Terminators” section requires one utterance
per main line and requires ordinary CHAT utterances to end in `.`, `?`, or `!`:
<https://talkbank.org/0info/manuals/CHAT.html#Utterance_Terminator>. Its
`@Options` section documents that `@Options: CA` removes the usual terminator
requirement for Conversation Analysis transcription:
<https://talkbank.org/0info/manuals/CHAT.html#Options_Header>.

## Missing terminator does not discard timing evidence

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A missing terminator does not authorize deletion of timing evidence. Internal
bullets, and a distinct grammar-routed terminal bullet when present, must retain
their values and source order in the model and serialized output.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Media:	bullet-retention, audio
*CHI:	hello 100_200 . 200_300
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Media:	bullet-retention, audio
*CHI:	hello 100_200 200_300
@End
```

#### Example 3

```chat
@UTF8

@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Media:	bullet-retention, audio
```

#### Example 4

```chat

@Media:	bullet-retention, audio
```

### CHAT Rule

E305 requires the ordinary utterance terminator. The legal controls assert only
that this rule is satisfied; they do not adjudicate every placement policy for
internal bullets. The CHAT manual's Audio and Video Time Marks section assigns
a separate scope to each bullet, so silently collapsing multiple bullets loses
information: <https://talkbank.org/0info/manuals/CHAT.html#Media_Linking>.

## Morphology requires its own terminator

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

### Description

This pair reduces the second lexical turn of
`corpus/reference/tiers/mor-gra.cha`, without its grammatical-relations tier.
The invalid example deletes only the morphology terminator, retaining the
complete main tier. The grammar permits this omission for diagnosis, but the
parser rejects the incomplete morphology with E305 rather than inventing a
terminator from the main tier.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	Mommy will get them .
%mor:	propn|Mommy aux|will verb|get-Inf pron|they-Prs-Acc-Plur .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	Mommy will get them .
%mor:	propn|Mommy aux|will verb|get-Inf pron|they-Prs-Acc-Plur 
@End
```

### CHAT Rule

A lexical `%mor` tier requires its own terminator. A terminated main tier does
not make an unterminated morphology tier valid. Any proposed terminator remains
a user choice, and the changed transcript must still satisfy cross-tier rules.

## Missing terminator before final postcodes

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

This pair reduces the first turn of
`corpus/reference/content/postcodes-and-freecodes.cha`. The invalid example
deletes only the period. Postcodes do not supply an utterance terminator.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello . [+ bch] [+ foo]
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello  [+ bch] [+ foo]
@End
```

### CHAT Rule

Outside CA mode, a main tier requires a terminator before its final postcodes.
A repair must preserve the postcodes and their final-code position, rather
than insert a terminator after them. The choice of terminator remains the
author's decision.

## Recovery does not prove a missing terminator

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A recovered main tier cannot establish that all its terminators are known.
Structural rejection remains actionable without guessing an additional
missing-terminator diagnostic or offering an insertion based on incomplete
content.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello world ] .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello world ]
@End
```

### CHAT Rule

Repair the structural fault first. Outside Conversation Analysis mode, the
resulting complete main tier must end with an appropriate utterance terminator.

## Standard terminator deletion preserves neighboring turns

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

Each invalid example deletes exactly one complete main-tier terminator from
`corpus/reference/content/terminators-standard.cha`, using the source-bound
admitted-seed mutation producer. The seed remains as the legal control. The
four deletions cover first, interior and final turns, and period, question and
exclamation forms; all other source bytes, including the preceding space and
terminal newline, are retained.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child, MOT Mother
@ID:	eng|corpus|CHI|3;00.||||Child|||
@ID:	eng|corpus|MOT|||||Mother|||
@Comment:	Standard terminators: period (.), question (?), exclamation (!)
@Comment:	Constructs: period, question, exclamation
*CHI:	I see a cat .
*MOT:	where is the cat ?
*CHI:	wow it is so big !
*MOT:	yes it is a big cat .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child, MOT Mother
@ID:	eng|corpus|CHI|3;00.||||Child|||
@ID:	eng|corpus|MOT|||||Mother|||
@Comment:	Standard terminators: period (.), question (?), exclamation (!)
@Comment:	Constructs: period, question, exclamation
*CHI:	I see a cat 
*MOT:	where is the cat ?
*CHI:	wow it is so big !
*MOT:	yes it is a big cat .
@End
```

#### Example 3

```chat

@Languages:	eng

@ID:	eng|corpus|MOT|||||Mother|||

*CHI:	I see a cat .
*MOT:	where is the cat
```

### CHAT Rule

Outside CA mode, each main tier requires its own terminator. A neighboring
speaker's terminated turn does not complete the unterminated turn. E305
reports the absent terminator while the parser retains the turn's typed
content. See [E305](E305.md) for the rule and CA exception.

## Missing terminator before timing media

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A timing bullet does not replace the main-tier utterance terminator. These
examples retain the timed reference document's dependent tiers, picture and
continuation text. Each invalid variant deletes exactly one typed terminator
from `corpus/reference/content/media-bullets.cha`, retaining surrounding spaces
and all other bytes. The control is that reference document without changes.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child, MOT Mother
@ID:	eng|sample|CHI|2;00.||||Child|||
@ID:	eng|sample|MOT|||||Mother|||
@Media:	media-bullets, video
@Comment:	Inline timing bullets on main tier and dependent tiers, inline_pic
@Comment:	Constructs: inline_bullet, timing_annotation, text_with_bullets,
	text_with_bullets_and_pics, media bullets on dependent tiers, inline_pic
*CHI:	hello there . 2041689_2042652
%cod:	this is junk 2041689_2042652
*MOT:	how are you ? 5041689_5042652
%act:	foo 2061689_2062652 bar 2061689_2062652
%com:	pic002 %pic:"a18/image002.jpg"
@End
```

#### Example 2
