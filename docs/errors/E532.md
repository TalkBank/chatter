# E532: Invalid participant role

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: header

**Status**: ✅ Active

## Description

A participant role, in `@Participants` or in the role field of `@ID`, is
not one of the roles the manual defines.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child, BOB InvalidRole
@ID:	eng|corpus|CHI|||||Target_Child|||
@ID:	eng|corpus|BOB|||||InvalidRole|||
*CHI:	hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child, MOT Mother, INV Investigator
@ID:	eng|corpus|CHI|||||Target_Child|||
@ID:	eng|corpus|MOT|||||Mother|||
@ID:	eng|corpus|INV|||||Investigator|||
*CHI:	hello .
@End
```

## CHAT Rule

The manual's role list under `@Participants` (https://talkbank.org/0info/manuals/CHAT.html#Participants_Header),
and the `@ID` role field, which takes the same values (https://talkbank.org/0info/manuals/CHAT.html#ID_Header).
