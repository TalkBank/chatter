## UnmatchedUnderlineBegin

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

An underline begin marker was found without a matching underline end marker
in the same utterance. Underline markers (used in CA transcription to mark
stressed syllables) must occur in matched begin/end pairs within a single
utterance.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	ERROR: Unmatched underline begin marker
*CHI:	hello world .
@End
```

## Underline balance beside attached CA pitch

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

Pitch shifts attach to a word independently of its underline markers. An
opening underline marker still requires a later closing underline marker
within the same utterance; a pitch marker cannot supply that close.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
*SPK:	↑rainbow .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@Options:	CA
@ID:	eng|sample|SPK|||||Speaker|||
*SPK:	↑rainbow .
@End
```

### CHAT Rule

Keep the `U+0002 U+0001` opening and `U+0002 U+0002` closing pairs balanced
in utterance order, including when underlining covers only part of a word
beside an attached pitch marker. The existing E356 rule applies unchanged.
