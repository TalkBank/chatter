# E246: Lengthening marker not after spoken material

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

## Description

Word-internal lengthening (`:`) requires preceding spoken material. A
shortening records omitted material, so `(he):` has nothing spoken to lengthen
and reports E246 as well as E209 (a shortening-only word). `hel:o` and
`(he)l:o` have preceding spoken text and do not violate this rule.
