# E232: Compound marker at word start

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

## Description

The first compound part must contain spoken material before the joining
marker (`+`). A stress marker alone does not supply that material. Valid
compounds have the form `left+right`, with spoken material in each part.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
@Comment:	ERROR: Compound marker (+) cannot be at word start
@Comment:	Invalid: '+hello' - Compound marker at start
*CHI:	+hello .
@End
```

## CHAT Rule

<https://talkbank.org/0info/manuals/CHAT.html#Compounds> documents the
`left+right` compound-word form. Supply spoken material before the first
joining marker or remove the marker; adding stress or another nonlexical marker
does not repair an empty first part. Literal word-initial `+` is also invalid,
although the grammar may reject it before word validation.
