# E232: Compound marker at word start

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word

**Status**: ✅ Active

## Description

Compound marker (`+`) cannot be at the start of a word. Valid compounds have
the form `left+right`, where both parts carry spoken material.

## CHAT Rule

<https://talkbank.org/0info/manuals/CHAT.html#Compounds> documents the
`left+right` compound-word form; `+` is a joining marker between two parts and
is not valid as a word-initial character.
