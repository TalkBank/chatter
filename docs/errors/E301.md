# E301: Empty speaker code

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

## Description

A main-tier prefix contains `*` and its delimiter but no speaker code, as in
`*:`. The line therefore cannot say which participant produced the utterance.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*:	hello world .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello world .
@End
```

## CHAT Rule

The CHAT manual's “Main Line” section requires every main tier to begin with an
asterisk followed by a speaker ID, colon, and tab:
<https://talkbank.org/0info/manuals/CHAT.html#Main_Line>. The speaker ID names
the participant responsible for the utterance; it cannot be empty.
