# E601: Invalid dependent tier content

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

The separator-only dependent-tier fixture is rejected by E316: no valid
morphology survives. Its observed tier identity and source remain in an explicit
`UnparsedMor` value attached to the preceding utterance. Tree-sitter admits that
attachment from surviving typed prefix and separator nodes, without reconstructing
morphology from ERROR text. The re2c backend retains the same shared recovery
state through its own parser. Model validation, including after JSON import,
continues to reject it; rendering preserves its source and does not certify it.
Valid controls remain legal. Parsed tiers retain their own typed diagnostics.

Malformed Phon alignment and interval bodies report E601 and retain their
original source as unparsed data. Model validation also rejects that state
after JSON readback; it is never an unsupported tier or an empty parsed tier.
