# E737: Modsyl does not reproduce the mod word

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

Stripping `:CODE` from each `%xmodsyl` unit must reproduce the
corresponding `%mod` word. A pause filler (`(.)`, `(..)`, `(...)`) on
`%xmodsyl` must mirror the same pause token as the `%mod` word at that
position.

This is a single-word reconstruction check. A grouped `%mod` item has no
single-word comparison target, so the grouped-source controls below do not
emit E737. That absence does not certify group-internal correspondence or
approve a pause as a substitute for grouped pronunciation. Recovered source
positions likewise cannot justify a reconstruction finding; parse errors remain.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	cat .
%mod:	kæt
%xmodsyl:	k:Oæ:N
@Comment:	ERROR: stripping codes from %xmodsyl gives 'kæ', which does not match %mod 'kæt'
@End
```
