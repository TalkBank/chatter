# E307

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Invalid speaker code

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance, file

**Status**: ✅ Active

### Description

A speaker code must be ASCII. It is structurally unusable if it contains the
colon reserved to terminate a main-tier speaker prefix or because it exceeds
CHAT's seven-character maximum.

Non-ASCII codes are rejected consistently in typed validation and main-tier
recovery as E307. E522 remains about participant/ID relationships, not character
syntax. Existing supported ASCII lowercase and punctuation forms remain legal.

```chat
@Participants:	A:B Child
@ID:	eng|corpus|A:B|||||Child|||
```

```chat
@End
```

### CHAT Rule

The CHAT manual's `@Participants` “Speaker ID” section says speaker IDs are
usually three letters and that CLAN accepts IDs up to seven characters:
<https://talkbank.org/0info/manuals/CHAT.html#Speaker_ID>. The main-line grammar
uses a colon after the ID, so a colon cannot also be part of the ID:
<https://talkbank.org/0info/manuals/CHAT.html#Main_Line>.

## Speaker code length and character boundaries

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: file

**Status**: ✅ Active

### Description

Speaker codes must be ASCII and at most seven characters long. These are
independent constraints: an overlong non-ASCII code violates both, and reporting
one fault must not hide the other. The same code is checked in participant
declarations, ID headers and the main-tier prefix.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	ABCDEFG Target_Child
@ID:	eng|corpus|ABCDEFG|||||Target_Child|||
*ABCDEFG:	hello .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	ABCDEFGH Target_Child
@ID:	eng|corpus|ABCDEFGH|||||Target_Child|||
*ABCDEFGH:	hello .
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	ABCDEFÉ Target_Child
@ID:	eng|corpus|ABCDEFÉ|||||Target_Child|||
*ABCDEFÉ:	hello .
@End
```

#### Example 4

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	ABCDEFÉH Target_Child
@ID:	eng|corpus|ABCDEFÉH|||||Target_Child|||

@End
```

### CHAT Rule

The seven-character maximum is described in the CHAT manual's
[Speaker ID section](https://talkbank.org/0info/manuals/CHAT.html#Speaker_ID).
Non-ASCII speaker IDs are rejected consistently by Chatter; Unicode participant
names remain separate from speaker codes.
