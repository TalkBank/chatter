# E376

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Replacement parse error

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

Failed to parse replacement annotation content. The `[:` replacement
annotation contains content that cannot be parsed as valid replacement
words.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
*CHI:	hello [:] world .
@End
```

### CHAT Rule

Replacement annotations use the form `word [: corrected_word]` where
the corrected form must contain at least one valid word. See the CHAT
manual: https://talkbank.org/0info/manuals/CHAT.pdf

## Empty replacements across body positions

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A replacement requires at least one corrected word. An empty replacement does not invent corrected speech. The same construct retains its specific rejection when moved among body positions and combined with final postcodes and timing.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	SPK Speaker
@ID:	eng|sample|SPK|||||Speaker|||
@Media:	body-ending-controls, audio
@Comment:	Préface café
*SPK:	café opening .
%com:	opening note
*SPK:	alder cedar . [+ bch] [+ first] 100_200
%com:	begin note
*SPK:	anchor maple drift ? [+ second] 200_300
%com:	middle note
*SPK:	willow pine . [+ third] 300_400
%com:	tail note
*SPK:	<moss <larch elm> [!]> [!] ! [+ fourth] 400_500
%com:	nested note
*SPK:	hazel . [+ fifth] [+ final] 500_600
%com:	ending note
*SPK:	finch closing .
%com:	closing note
@End
```
