# E401: Duplicate dependent tier

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

## Description

An utterance carries the same dependent tier twice (`%mor` twice, `%com`
twice). Each dependent tier annotates its utterance once; a second copy
either duplicates or contradicts the first.

## Examples

### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
%mor:	co|hello .
%mor:	co|hello .
@End
```

### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
%com:	one
%com:	two
@End
```

### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	hello .
%mor:	co|hello .
%com:	fine
@End
```

## CHAT Rule

Dependent tiers "follow the main tier ... each dependent tier begins with
`%` and a three-letter code" (https://talkbank.org/0info/manuals/CHAT.html#Dependent_Tiers); the manual lists each
tier once per utterance.
