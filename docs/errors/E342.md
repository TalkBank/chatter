# E342

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Missing required element (recovery placeholder)

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: word, utterance, tier, header

**Status**: ✅ Active

### Description

Tree-sitter recovered the parse by inserting a MISSING placeholder for a
required element that the source does not contain: an annotation after an
angle-bracket group, a word segment inside a replacement. Recovery is not
validity, so the placeholder is reported.

Not every absent lexical value becomes a MISSING placeholder. Deleting the
value after a media-status comma retains a zero-width `generic_media_status`
in the current CST. Chatter preserves that empty unsupported value and reports
E536 during validation, with no E342. The control/mutation pair records this
boundary: source association and present-node identity do not prove a nonempty
payload. The empty status is not equivalent to omitting the optional status
group altogether.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	PAR Participant
@ID:	eng|corpus|PAR|||||Participant|||
*PAR:	<I don't> &-uh I know xxx .
@End
```

#### Example 2

### CHAT Rule

Scoped symbols follow the group they scope over (https://talkbank.org/0info/manuals/CHAT.html#Scoped_Symbols);
a replacement carries replacing text (https://talkbank.org/0info/manuals/CHAT.html#Replacement_Scope).

## Empty scoped content

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A scoped annotation requires material inside its angle-bracket scope. These
paired examples delete only the group's sole word while retaining the closing
bracket, annotation, subsequent speech and utterance terminator.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	<hello> [/] hello .
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	<> [/] hello .
@End
```

#### Example 3

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	<hello> [= greeting] hello .
@End
```

#### Example 4

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	<> [= greeting] hello .
@End
```

### CHAT Rule

A scope identifies the material to which an annotation applies. An empty scope
has no such material. Parsing may recover missing content, but that recovery
is not a valid empty utterance model or a reason to discard its diagnostics.
