# E705

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## %mor has fewer items than the main tier has words

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

### Description

The `%mor` tier has fewer items than the main tier has alignable words
(ordinary words and tag markers), so the last words have no analysis.
Terminators are checked separately by E707 and are not included in this
item count; see `spec/docs/ALIGNMENT_RULES.md`.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|2;06.|male|||Target_Child|||
@Comment:	Note: Tag markers are alignable content
*CHI:	I want ± cookie .
%mor:	pro|I v|want n|cookie .
@Comment:	ERROR: Tag marker ± should have a mor item
@Comment:	Main tier alignable: I, want, ±, cookie = 4 words
@Comment:	Mor tier: Should have 4 items (missing item for ±)
@End
```

#### Example 2

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|2;06.|male|||Target_Child|||
*CHI:	I want cookie .
%mor:	pro|I v|want .
@Comment:	ERROR: Main tier has 3 words but %mor only has 2 items (missing n|cookie)
@End
```

### CHAT Rule

"The %mor tier ... contains one item for each word on the main tier"
(https://talkbank.org/0info/manuals/CHAT.html#Morphological_Tier); which main-tier material counts is the
alignment rule (retraced material and scoped annotations are excluded).

## MOR item count is distinct from expanded chunks

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: tier

**Status**: ✅ Active

### Description

The main tier aligns to MOR items, not expanded clitic chunks. Replacing one admitted item boundary with a tilde decreases the item count while preserving every word chunk and every GRA relation. A matching MOR/GRA chunk count cannot make this main/MOR mismatch valid.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Child
@ID:	eng|corpus|CHI|||||Child|||
@Comment:	Authored MOR/GRA combinations: repeated post-clitics, POS subcategories,
	ordered flat/keyed/multivalue features, Unicode lemmas and a compound lemma.
	The middle turn has four main words and MOR items but seven GRA word chunks,
	including two post-clitics and the terminator. Neighboring turns are sentinels.
*CHI:	start .
%mor:	verb|start .
%gra:	1|0|ROOT 2|1|PUNCT
%com:	before café
*CHI:	we'd've found café icecream .
%mor:	pron:pers|we-Nom-Person=1~aux|have-Tense=Past~aux|have-Mood=Ind-Polarity=Pos verb|find-Past noun|café-Case=Acc noun|ice_cream-PronType=Int,Rel .
%gra:	1|4|NSUBJ 2|4|AUX 3|2|AUX 4|0|ROOT 5|4|OBJ 6|4|OBJ 7|4|PUNCT
%com:	middle naïve
*CHI:	finish .
%mor:	verb|finish .
%gra:	1|0|ROOT 2|1|PUNCT
%com:	after résumé
@End
```
