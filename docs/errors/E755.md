# E755

> Several rules are reported under this code. Each section below is a
> separate specification with its own status.

## Utterance language not declared in @Languages

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

A `[- CODE]` precode marks a whole utterance as being in another
language: substantial language presence in the transcript. The
`@Languages` header declares the transcript's substantial languages,
so an utterance-level language missing from it leaves the header
misrepresenting the transcript. Matches CLAN CHECK error 152
("Language is not defined on @Languages header tier."). Ruled
2026-07-15 (maintainer decision,
docs/design/2026-07-15-at-s-language-declaration-decision.md, part 3):
declaration IS required at utterance level, deliberately UNLIKE
word-level `@s:CODE` insertions, which remain free (part 1 of the
same ruling; the corpus grounding found 0 of 7,167 precode-bearing
files violate this invariant while 854 files legitimately use
undeclared word-level codes).

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng
@Participants:	CHI Target_Child
@ID:	eng|corpus|CHI|||||Target_Child|||
*CHI:	[- fra] bonjour .
@Comment:	ERROR: utterance language fra is not declared
@End
```

### CHAT Rule

`@Languages` declares the transcript's substantial languages;
utterance-level presence is substantial. Parity entry:
`crates/talkbank-parser-tests/tests/check_parity/manifest.json`
CHECK 152.

## Language declaration in combined preludes

> ✅ Active; This check is active in the validator.

**Kind**: Invalidity

**Level**: utterance

**Status**: ✅ Active

### Description

The header declares eng and zho. Switching an admitted whole-utterance precode to fra changes only that source-owned token and violates the existing declaration requirement. Switching between the declared languages is legal. E755 is located at the owning main-tier start, not at the precode token; word-level suffix policy is unchanged.

### Examples

#### Example 1

```chat
@UTF8
@Begin
@Languages:	eng, zho
@Participants:	SPK Speaker
@ID:	eng, zho|sample|SPK|||||Speaker|||
@Media:	prelude-controls, audio
@Comment:	Préface café
*SPK:	café opening .
%com:	opening note
*SPK:	+< +^ [- zho] bamboo forest . [+ bch] 100_200
%com:	combined note
*SPK:	+, [- eng] birch grove ? [+ second] 200_300
%com:	completion note
*SPK:	[- zho] cedar tree . [+ third] 300_400
%com:	language note
*SPK:	+^ +< fern garden ! [+ fourth] 400_500
%com:	linkers note
*SPK:	finch closing .
%com:	closing note
@End
```
