# E001: InternalError

> ✅ Active (not reachable from CHAT)

**Kind**: InternalFailure

**Status**: ✅ Active (not reachable from CHAT)

## Description

Internal invariant failure. This error indicates a bug in the parser
itself, not in the CHAT input. It is not a CHAT validity rule.

The run failed: neither a valid nor an invalid verdict may be inferred from
this diagnostic. Do not repair the transcript to work around it. Preserve the
input and report the failure. Internal failures must block accepted-model
admission and must not be cached as a validation verdict.
